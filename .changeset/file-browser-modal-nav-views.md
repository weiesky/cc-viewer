"cc-viewer": patch
---

File browser modal: back/forward navigation history (Alt+←/→, Cmd/Ctrl+[/]), address bar (double-click the breadcrumb blank area or Ctrl/Cmd+L to edit; supports relative + absolute paths, file paths locate and preview), list/grid view toggle with per-directory preference memory, server-driven sorting by name/size/modified-time (the list view shows sortable column headers), and a current-folder filename filter with inline highlighting.
