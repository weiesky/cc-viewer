**fix(chat): queued/send-now user messages now render in the conversation panel.** After an interrupt-driven delivery (Esc/Stop, or the queue bubble's "Send now"), the client session tail held the aborted partial assistant while the next wire replay omitted it and placed the queued user prompt at the divergence point; the reverse-anchor window missed and the `newLen > curLen` fallback only pushed messages from `curLen` — permanently skipping the queued prompt (its reply rendered as an orphan assistant bubble). The fallback in `mergeMainAgentSessions` is now a deepest-common-prefix extension: it finds the longest fingerprint-matching prefix `L`, truncates the divergent tail (aligning the client with the wire truth), and appends `newMessages[L..]`. No-divergence cases degrade to byte-identical old behavior (`L === curLen`); zero-overlap degenerates to wholesale replace, matching the `_partialData` / shrink branches' wire-is-truth philosophy. Covers both SDK and PTY modes (the shared replay path; documented as WIRE_FORMAT.md §3.8). Regression tests added for the interrupt-divergence shape (tool_use/text variants), multi-queue chains, re-rendered partials, and the zero-prefix replace.
