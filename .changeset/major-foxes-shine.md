Built-in model system prompts are now default-effective, with an override + disable mechanism. The six shipped presets (`deepseek-v4-pro`, `deepseek-v4-flash`, `GLM-5.2`, `Qwen-3.7-Max`, `kimi-k2.7-code`, `kimi-k3`) are injected automatically at spawn when the resolved model matches and no user entry exists (workspace > global > built-in; user files always win — configurations that already have a matching user entry, like a global `K3_SYSTEM.md`, see zero change). **Note for Default-file users:** a built-in hit carries the same semantics as a user-entry hit — it fully replaces the Default `CC_SYSTEM.md`/`CC_APPEND_SYSTEM.md` sentinels for that launch (all six presets are override-mode), so if your resolved model is one of the six and you rely on the Default files, the built-in prompt takes over (visible in the launch log as `builtin:<NAME>`; disable per-model via the modal to keep the old behavior). The alias expansion now also covers bare shorthand ids with bracket suffixes (e.g. `k3[1m]`), so dormant user entries named for those models may newly match. New `server/lib/builtin-model-prompts.js` implements manifest-driven matching (reusing the `MODEL_ID_ALIASES` expansion so bare `k3` hits `kimi-k3`), per-scope tombstones (`system_prompt/.builtin-disabled.json`) that disable individual built-ins, and content-addressed temp-file materialization (read-back hash-verified) so injection stays on the `--system-prompt-file` path (snapshot pinning/Bind A unaffected; boundary markers stripped, `${...}` rendered by the usual pipeline). Failures in the built-in layer degrade to the Default sentinels (never throw). The Edit System Prompt modal shows built-in tabs with a Built-in badge — edit-and-save materializes an override, the tab × disables/enables via tombstone (new POST action with `bad_action`/`unknown_builtin` guards), and the header entry stays visible marked "Disabled" for re-enabling. `CCV_DISABLE_AUTO_SYSTEM_PROMPT=1` and manual synonym flags keep their semantics; `system-prompt-status` mirrors spawn behavior and reports `builtinDisabled` when the current model's built-in is tombstoned. Docs updated across all 18 README locales.
