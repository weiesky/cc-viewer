`ccv -SDK` headless mode now shares the full PTY-mode surface: SDK launches run a headless `claude` subprocess through the same observation plane (loopback proxy + fetch hook + wire-format v2 storage + SSE streaming/typewriter), with synthetic display entries retired from the sdk-manager. Tool approvals (Bash/Edit/Write/NotebookEdit/WebFetch/WebSearch) ride `canUseTool` into the Web UI with allow/deny/allow-for-session; `AskUserQuestion` and `ExitPlanMode` use the same modal flow. A shared `server/lib/approval-policy.js` keeps the IM deny short-circuit (`CCV_IM_DENY`) and the npm-publish hard gate (forced approval even under `--d`) identical across both modes. The terminal WebSocket now connects in SDK mode too (user messages, approval answers, interrupt), query failures surface as an in-app toast, pending approvals survive a WS disconnect via connection replay (PTY perm hooks included), typing `/` shows the session's slash-command hint, and compaction boundaries render as a system notice. Launch args `--model`/`-c`/`-r <id>`/`--fork-session` map to native SDK options (spawn config extracted into shared `server/lib/launch-config.js`, consumed by both PTY and SDK launches with resume-pinned system prompts). Falls back to PTY mode when the Agent SDK is unavailable.
