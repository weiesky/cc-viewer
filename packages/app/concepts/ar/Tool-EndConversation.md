# EndConversation

ينهي المحادثة الحالية ويمنع إرسال أي رسائل أخرى.

## متى يُستخدم

- فقط عند إساءة مستمرة من المستخدم، أو عندما يطلب المستخدم صراحةً عرضاً لهذه الأداة.

هذا إجراء الملاذ الأخير: تتطلب قواعد الأداة نفسها تحذير المستخدم أولاً والتأكيد قبل الاستخدام، ويجب ألا تُستخدم أبداً في حالات إيذاء النفس أو المواقف المرتبطة بالأذى.

## التفعيل

- يتطلب Claude Code 2.1.213+ ونموذجاً من عائلة Opus 4.8 / Sonnet 5 / Fable 5 أو ما بعدها.
- جلسات الطرفية التفاعلية فقط — لا يتوفر أبداً في وضع `--bare`، ولا يتوفر أبداً للوكلاء الفرعيين.
- غير متاح على Amazon Bedrock وClaude Platform on AWS وVertex AI وMicrosoft Foundry أو البوابات السحابية.
- يتطلب علَم ميزة من جهة الخادم — معظم الجلسات لا تعرض هذه الأداة.

## المعاملات

لا تأخذ هذه الأداة أي معاملات.

## أمثلة

### مثال 1: إنهاء المحادثة

```
EndConversation()
```

التدفق من خطوتين: الاستدعاء الأول يُعيد رسالة تأمل؛ والاستدعاء الثاني بعده مباشرة ينهي المحادثة فعلياً (`ended: true`).

## ملاحظات

- خاضعة لبوابات شديدة: تتطلب نموذجاً مدعوماً ونقطة دخول CLI وعلَم ميزة من جهة الخادم — معظم الجلسات لا تعرض هذه الأداة.
- بمجرد انتهائها، لا يمكن إرسال أي رسائل أخرى في المحادثة.
