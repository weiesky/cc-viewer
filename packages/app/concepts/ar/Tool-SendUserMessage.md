# SendUserMessage

يرسل رسالة إلى المستخدم — قناة الإخراج المرئي الأساسية في الجلسات ذات الطراز الموجز (brief). تُعرف أيضاً بالاسم المستعار القديم `Brief`.

## متى يُستخدم

- الرد على شيء قاله المستخدم للتو (`status="normal"`).
- إظهار شيء لم يطلبه المستخدم ويحتاج رؤيته الآن استباقياً — مهمة تكتمل أثناء غيابه، عائق صادفته، تحديث حالة غير مطلوب (`status="proactive"`).

## التفعيل

- مخفي في الجلسات التفاعلية افتراضياً؛ معظم جلسات CLI التفاعلية تتحدث إلى المستخدم مباشرة بدلاً من ذلك.
- مُفعَّل في وضع brief أو عبر أعلام ميزات من جهة الخادم.

## المعاملات

في وضع brief:

- `message` (سلسلة، مطلوب): الرسالة للمستخدم. يدعم تنسيق markdown.
- `attachments` (مصفوفة، اختياري): مرفقات تُعرض بجانب الرسالة. كل إدخال إما مسار ملف (مطلق أو نسبة إلى cwd) لملف قابل للقراءة محلياً، أو كائن `{file_uuid, file_name, size, is_image}` مُحلَّل مسبقاً تم الحصول عليه من أداة جهاز مثل `attach_file`.
- `status` (سلسلة، مطلوب): `proactive` للتحديثات غير المطلوبة التي يحتاجها المستخدم الآن؛ و`normal` عند الرد على المستخدم.

في البناءات غير الموجزة يتوفر `message` فقط.

## أمثلة

### مثال 1: إشعار اكتمال استباقي

```
SendUserMessage(
  message="The migration finished — 42 files updated, tests green.",
  status="proactive"
)
```

## ملاحظات

- استخدم `proactive` باعتدال — فهو مخصص للأمور التي تحتاج انتباه المستخدم فعلاً الآن.
