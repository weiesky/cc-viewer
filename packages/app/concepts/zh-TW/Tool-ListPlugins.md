# ListPlugins

列出使用者已啟用的 claude.ai 外掛，可選擇性以關鍵字過濾。

## 使用時機

- 你需要知道哪些外掛已啟用——例如，在 `SuggestPluginInstall` 卡片之後確認安裝了什麼。
- 使用者詢問他們有哪些外掛。

## 啟用方式

- 需要外掛登錄檔存取權限。
- 可用性取決於工作階段類型與功能推出——在 HIPAA 環境中停用，在遠端工作階段中一律可用。

## 參數

- `keywords`（string 陣列，選填）：過濾清單——最多 8 個項目，每個 1–64 個字元。省略則列出全部。

## 範例

### 範例 1：列出已啟用的外掛

```
ListPlugins()
```

### 範例 2：以關鍵字過濾

```
ListPlugins(keywords=["figma"])
```

## 注意事項

- 若外掛目錄無法連線（禁止存取），工具會降級為帶警告的空清單，而非失敗。
