# EndConversation

結束目前對話，並阻止任何進一步的訊息傳送。

## 使用時機

- 僅限於持續的使用者濫用，或使用者明確要求示範此工具。

這是最後手段的動作：工具本身的規則要求先警告使用者並在使用前確認，且絕不可用於自傷或傷害相關的情境。

## 啟用方式

- 需要 Claude Code 2.1.213+ 以及 Opus 4.8 / Sonnet 5 / Fable 5 或之後系列的模型。
- 僅限互動式終端機工作階段——絕不在 `--bare` 模式中，也絕不提供給子代理。
- 在 Amazon Bedrock、Claude Platform on AWS、Vertex AI、Microsoft Foundry 或雲端閘道上不可用。
- 需要伺服器端功能旗標——大多數工作階段不提供此工具。

## 參數

此工具不接受任何參數。

## 範例

### 範例 1：結束對話

```
EndConversation()
```

流程分兩步：第一次呼叫回傳反思訊息；緊接著的第二次呼叫才實際結束對話（`ended: true`）。

## 注意事項

- 高度門控：需要受支援的模型、CLI 進入點與伺服器端功能旗標——大多數工作階段不提供此工具。
- 一旦結束，對話中就無法再傳送任何訊息。
