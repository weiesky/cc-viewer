# ReadNotifications

讀取目前工作階段中排入佇列、等待助理處理的通知——已訂閱 PR 上的 GitHub 活動（`github_webhook`）、排程觸發器觸發（`trigger_fire`），以及來自其他 Claude 工作階段的訊息（`mcp_send_message`）。

## 使用時機

- 你收到某事件發生的通知——已訂閱的 PR 更新、排程觸發器觸發、其他工作階段傳訊息給你——並需要實際的內容。
- 清空積壓通知：大型批次會分成多部分回傳，因此要持續呼叫，直到結果回報 `remaining` 為 0。

## 參數

此工具不接受任何參數。

## 範例

### 範例 1：清空待處理通知

```
ReadNotifications()
```

依最舊優先的順序回傳佇列中的通知。結果包含一個 `remaining` 計數，代表這次清空後仍在佇列中的通知數量——再次呼叫此工具即可讀取它們。

## 注意事項

- 每次清空都有大小預算：後續呼叫會回傳同一個佇列的其餘部分（加上任何新抵達的項目），而不只是新抵達的通知。持續循環呼叫，直到 `remaining` 為 0。
- 通知源自已訂閱 PR 上的 GitHub webhook、排程觸發器，以及來自其他 Claude 工作階段的訊息；目前版本沒有過濾參數。
