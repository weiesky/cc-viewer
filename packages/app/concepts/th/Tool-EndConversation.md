# EndConversation

จบ conversation ปัจจุบันและป้องกันการส่งข้อความใด ๆ เพิ่มเติม

## เมื่อใดควรใช้

- เฉพาะกรณีผู้ใช้ทำร้ายอย่างต่อเนื่อง หรือเมื่อผู้ใช้ขอให้สาธิตเครื่องมือนี้อย่างชัดเจนเท่านั้น

นี่คือการกระทำขั้นสุดท้าย: กฎของเครื่องมือเองกำหนดให้เตือนผู้ใช้ก่อนและยืนยันก่อนใช้ และห้ามใช้ในสถานการณ์ที่เกี่ยวข้องกับการทำร้ายตัวเองหรืออันตรายโดยเด็ดขาด

## การเปิดใช้งาน

- ต้องใช้ Claude Code 2.1.213+ และโมเดลจากตระกูล Opus 4.8 / Sonnet 5 / Fable 5 หรือใหม่กว่า
- เฉพาะเซสชันเทอร์มินัลแบบ interactive เท่านั้น — ไม่มีในโหมด `--bare` และไม่พร้อมใช้งานสำหรับ subagent
- ไม่พร้อมใช้งานบน Amazon Bedrock, Claude Platform on AWS, Vertex AI, Microsoft Foundry, หรือ cloud gateway
- ต้องใช้ feature flag ฝั่ง server — เซสชันส่วนใหญ่ไม่มีเครื่องมือนี้

## พารามิเตอร์

เครื่องมือนี้ไม่มีพารามิเตอร์

## ตัวอย่าง

### ตัวอย่างที่ 1: จบ conversation

```
EndConversation()
```

กระบวนการมีสองขั้น: การเรียกครั้งแรกส่งคืนข้อความ reflection การเรียกครั้งที่สองทันทีหลังจากนั้นจึงจบ conversation จริง ๆ (`ended: true`)

## หมายเหตุ

- ถูก gated อย่างเข้มงวด: ต้องใช้โมเดลที่รองรับ, CLI entrypoint, และ feature flag ฝั่ง server — เซสชันส่วนใหญ่ไม่มีเครื่องมือนี้
- เมื่อจบแล้ว จะส่งข้อความเพิ่มใน conversation ไม่ได้อีก
