# ReadNotifications

อ่านการแจ้งเตือนที่รออยู่ในคิวสำหรับผู้ช่วยในเซสชันปัจจุบัน — กิจกรรม GitHub บน PR ที่ติดตาม (`github_webhook`), การยิงของ trigger ที่ตั้งเวลา (`trigger_fire`), และข้อความที่มาจากเซสชัน Claude อื่น (`mcp_send_message`)

## เมื่อใดควรใช้

- คุณได้รับการแจ้งเตือนว่ามีบางอย่างเกิดขึ้น — PR ที่ติดตามอัปเดต, trigger ที่ตั้งเวลาถูกยิง, เซสชันอื่นส่งข้อความมา — และต้องการ payload จริง
- เคลียร์ backlog: batch ขนาดใหญ่ถูกส่งคืนเป็นส่วน ๆ ดังนั้นให้เรียกต่อไปเรื่อย ๆ จนกว่าผลลัพธ์จะรายงาน 0 `remaining`

## พารามิเตอร์

เครื่องมือนี้ไม่มีพารามิเตอร์

## ตัวอย่าง

### ตัวอย่างที่ 1: เคลียร์การแจ้งเตือนที่ค้างอยู่

```
ReadNotifications()
```

ส่งคืนการแจ้งเตือนในคิวโดยเรียงจากเก่าสุดก่อน ผลลัพธ์มีจำนวน `remaining` ของการแจ้งเตือนที่ยังอยู่ในคิวหลังจากการเคลียร์ครั้งนี้ — เรียกเครื่องมือนี้อีกครั้งเพื่ออ่านการแจ้งเตือนที่เหลือ

## หมายเหตุ

- การเคลียร์ถูกจำกัดด้วยขนาด (size-budgeted): การเรียกครั้งถัดไปจะคืนส่วนที่เหลือของคิวเดิม (บวกของที่เพิ่งเข้ามาใหม่) ไม่ใช่เฉพาะของใหม่เท่านั้น วนเรียกจนกว่า `remaining` จะเป็น 0
- การแจ้งเตือนมาจาก GitHub webhook บน PR ที่ติดตาม, trigger ที่ตั้งเวลา, และข้อความจากเซสชัน Claude อื่น; ปัจจุบันยังไม่มีพารามิเตอร์กรอง
