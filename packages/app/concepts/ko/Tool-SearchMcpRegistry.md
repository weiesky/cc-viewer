# SearchMcpRegistry

MCP 커넥터 레지스트리를 키워드로 검색하여 태스크 완료에 도움이 될 커넥터를 발견합니다.

## 사용 시점

- 태스크가 외부 서비스(데이터베이스, 이슈 트래커, SaaS API)의 이점을 얻을 수 있고, 이를 위한 MCP 커넥터가 존재하는지 확인하고 싶습니다.
- 사용자가 제품 이름을 말하며 연결을 요청합니다 — 일치하는 커넥터를 레지스트리에서 검색하십시오.

## 활성화

- 퍼스트파티 API의 원격(claude.ai) 세션에서만 사용할 수 있습니다.

## 매개변수

- `keywords` (array of strings, 필수): 사용자의 의도 또는 명명된 제품을 설명하는 키워드 구절. 1-8개 항목, 각각 1-64자.

## 예시

### 예시 1: 명명된 제품의 커넥터 찾기

```
SearchMcpRegistry(keywords=["linear", "issue tracker"])
```

커넥터가 키워드와 일치하는 레지스트리 항목을 반환합니다. `SuggestConnectors`로 전체 커넥터 상세 정보를 확인하십시오.

## 참고사항

- 읽기 전용이며 동시성에 안전합니다. 결과 크기는 제한됩니다.
- 검색은 아무것도 설치하지 않습니다 — 순수한 발견입니다.
