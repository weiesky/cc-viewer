# ReadNotifications

현재 세션에서 어시스턴트에게 대기 중인 알림을 읽습니다 — 구독한 PR의 GitHub 활동(`github_webhook`), 스케줄된 트리거 발화(`trigger_fire`), 그리고 다른 Claude 세션에서 도착한 메시지(`mcp_send_message`).

## 사용 시점

- 무언가 일어났다는 알림을 받았고(구독한 PR 업데이트, 스케줄된 트리거 발화, 다른 세션의 메시지) 실제 페이로드가 필요합니다.
- 백로그 소진: 큰 배치는 부분적으로 반환되므로, 결과가 0 `remaining`을 보고할 때까지 계속 호출하십시오.

## 매개변수

이 도구는 매개변수를 받지 않습니다.

## 예시

### 예시 1: 보류 중인 알림 소진

```
ReadNotifications()
```

대기 중인 알림을 가장 오래된 것부터 반환합니다. 결과에는 이번 소진 후에도 여전히 대기 중인 알림의 `remaining` 개수가 포함됩니다 — 나머지를 읽으려면 도구를 다시 호출하십시오.

## 참고사항

- 소진은 크기 예산이 정해져 있습니다: 후속 호출은 새 도착분만이 아니라 같은 큐의 나머지(새로 도착한 것을 더한)를 반환합니다. `remaining`이 0이 될 때까지 반복하십시오.
- 알림은 구독한 PR의 GitHub 웹훅, 스케줄된 트리거, 그리고 다른 Claude 세션의 메시지에서 발생합니다. 현재 버전에는 필터링 매개변수가 없습니다.
