# ReadNotifications

現在のセッションでアシスタントに対してキューに入れられた通知 — サブスクライブした PR の GitHub アクティビティ (`github_webhook`)、スケジュールトリガーの発火 (`trigger_fire`)、他の Claude セッションから到着したメッセージ (`mcp_send_message`) — を読み取ります。

## 使用タイミング

- 何かが起きたと通知され (サブスクライブした PR の更新、スケジュールトリガーの発火、他のセッションからのメッセージ)、実際のペイロードが必要な場合。
- バックログの排出: 大きなバッチは分割して返されるため、結果が `remaining` 0 を報告するまで呼び出し続けてください。

## パラメータ

このツールはパラメータを取りません。

## 例

### 例 1: 保留中の通知を排出

```
ReadNotifications()
```

キューに入れられた通知を古いものから順に返します。結果には、この排出の後もまだキューに残っている通知の `remaining` カウントが含まれます — それらを読むにはもう一度ツールを呼び出してください。

## 注意事項

- 排出にはサイズの上限があります: フォローアップの呼び出しは、新しい到着分だけではなく、同じキューの残り (新しく到着した分も含む) を返します。`remaining` が 0 になるまでループしてください。
- 通知は、サブスクライブした PR の GitHub ウェブフック、スケジュールトリガー、他の Claude セッションからのメッセージから発生します。現在のバージョンにはフィルタリングパラメータはありません。
