# ListSkills

ユーザーの有効な claude.ai スキルを一覧表示します。オプションでキーワードで絞り込めます。

## 使用タイミング

- 現在有効なスキルの権威あるリストが必要な場合 — スキルを呼び出す前、または `SuggestSkills` カードが何を追加したかを確認するため。
- ユーザーが自分にどのスキルがあるかを尋ねた場合。

## 有効化

- プラグインレジストリへのアクセス権限が必要です。
- HIPAA 環境では無効化されます。
- リモートセッションでは常に利用可能です。

## パラメータ

- `keywords` (array of strings, optional): 一覧の絞り込み — 最大 8 項目、各 1〜64 文字。省略するとすべてを一覧表示します。

## 例

### 例 1: 有効なスキルを一覧表示

```
ListSkills()
```

### 例 2: キーワードで絞り込む

```
ListSkills(keywords=["review"])
```

## 注意事項

- カタログに到達できない場合 (forbidden)、ツールは失敗せずに警告付きの空リストへとデグレードします。
- これは*有効な*スキルの一覧です。ユーザーが追加できるスキルを提示するには `SuggestSkills` を使用してください。
