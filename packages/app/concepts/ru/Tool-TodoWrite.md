# TodoWrite

Записывает структурированный список дел для текущей сессии, заменяя предыдущий список. Каждый пункт несёт свой текст, статус и форму в настоящем продолженном времени, показываемую в индикаторах прогресса.

## Когда использовать

- Задача состоит из нескольких отдельных шагов, и их отслеживание помогает вам (и пользователю) видеть прогресс.
- Пользователь явно просит список дел.
- Вы хотите пометить ровно один пункт как выполняемый, пока остальные остаются ожидающими или завершёнными.

## Активация

- Устаревший инструмент: по умолчанию отключён в сессиях, предлагающих инструменты задач (`TaskCreate`, `TaskUpdate`, `TaskList`).
- Заново включите его через `CLAUDE_CODE_ENABLE_TASKS=0`.

## Параметры

- `todos` (array, обязательный): полный обновлённый список дел. Каждая запись содержит:
  - `content` (string): описание задачи.
  - `status` (string): одно из `pending`, `in_progress`, `completed`.
  - `activeForm` (string): текст в настоящем продолженном времени, показываемый, пока пункт выполняется (например, "Running tests").

## Примеры

### Пример 1: отслеживание изменения из трёх шагов

```
TodoWrite(
  todos=[
    {content="Update the parser", status="in_progress", activeForm="Updating the parser"},
    {content="Add unit tests", status="pending", activeForm="Adding unit tests"},
    {content="Run the full test suite", status="pending", activeForm="Running the full test suite"}
  ]
)
```

Весь список перезаписывается при каждом вызове — всегда включайте все пункты, а не только изменившиеся.

## Примечания

- Список заменяется целиком при каждом вызове; чтобы обновить один пункт, отправьте заново все пункты с новым статусом.
- Держите ровно один пункт в состоянии `in_progress` одновременно.
- В сессиях, где включены инструменты структурированных задач (`TaskCreate`/`TaskUpdate`/`TaskList`), каркас может предлагать их вместо `TodoWrite` — предпочитайте тот набор инструментов, который объявлен.
