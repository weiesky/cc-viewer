# Projects

Управляет проектными документами в базе знаний проекта пользователя Claude: читает, ищет, записывает и удаляет документы, а также получает информацию о проекте.

## Когда использовать

- Сохранить документ (результат работы, заметки, справочный материал) в проект пользователя, чтобы он пережил сессию.
- Прочитать или найти существующие проектные документы, чтобы заземлить текущую задачу в предыдущем контексте.
- Загрузить локальный файл в проект, не загружая его содержимое в контекст.
- Удалить устаревший проектный документ.

## Параметры

- `method` (string, обязательный): одно из `project_info`, `project_read`, `project_search`, `project_write`, `project_delete`.
- `path` (string, необязательный): для `project_read`/`project_write`/`project_delete`: путь к документу. Для `project_write`: существующий путь заменяется на месте; новое голое имя файла (без "/") получает неймспейс `claude/<name>`.
- `content` (string, необязательный): для `project_write`: встроенный текст документа. Взаимоисключающий с `local_path`.
- `local_path` (string, необязательный): для `project_write`: файл внутри рабочей директории для загрузки — содержимое никогда не попадает в ваш контекст. Взаимоисключающий с `content`.
- `present_to_user` (boolean, необязательный): для `project_write`: пометить этот документ как результат, который пользователю нужно увидеть. По умолчанию false; не задавайте для рутинных сохранений и массовых записей.
- `query` (string, необязательный): для `project_search`: запрос к базе знаний.
- `n` (number, необязательный): для `project_search`: количество совпадений (по умолчанию 5).

## Примеры

### Пример 1: записать результат в проект

```
Projects(
  method="project_write",
  path="claude/migration-plan.md",
  local_path="./migration-plan.md",
  present_to_user=true
)
```

Загружает локальный файл, не подтягивая его содержимое в контекст, и помечает его как результат для пользователя.

### Пример 2: поиск по базе знаний

```
Projects(method="project_search", query="authentication refresh tokens", n=5)
```

## Примечания

- `content` — для текста, который вы составляете inline; `local_path` — для всего, что уже на диске — никогда не смешивайте их.
- Используйте `present_to_user=true` экономно: только для того единственного документа, который пользователь запросил или с которым должен действовать.
