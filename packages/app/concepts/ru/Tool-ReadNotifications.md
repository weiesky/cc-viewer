# ReadNotifications

Читает уведомления, поставленные в очередь для ассистента в текущей сессии — активность GitHub по подписанным PR (`github_webhook`), срабатывания запланированных триггеров (`trigger_fire`) и сообщения, приходящие из других сессий Claude (`mcp_send_message`).

## Когда использовать

- Вас уведомили, что что-то произошло — подписанный PR обновился, запланированный триггер сработал, другая сессия прислала вам сообщение — и вам нужны сами данные (payload).
- Разгрузка накопившейся очереди: большие партии возвращаются по частям, поэтому продолжайте вызывать инструмент, пока результат не сообщит 0 `remaining`.

## Параметры

Этот инструмент не принимает параметров.

## Примеры

### Пример 1: разгрузить очередь уведомлений

```
ReadNotifications()
```

Возвращает поставленные в очередь уведомления, начиная с самых старых. Результат содержит счётчик `remaining` — сколько уведомлений осталось в очереди после этого чтения; вызовите инструмент ещё раз, чтобы прочитать их.

## Примечания

- Выгрузка ограничена по размеру: последующий вызов возвращает остаток ТОЙ ЖЕ очереди (плюс всё, что пришло заново), а не только новые поступления. Повторяйте цикл, пока `remaining` не станет 0.
- Уведомления порождаются вебхуками GitHub по подписанным PR, запланированными триггерами и сообщениями из других сессий Claude; в текущей версии параметра фильтрации нет.
