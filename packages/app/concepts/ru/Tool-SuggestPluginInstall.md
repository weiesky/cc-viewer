# SuggestPluginInstall

Рендерит inline-карточку установки плагина из результатов `SearchPlugins`, привязывая предложения плагинов к запросу пользователя.

## Когда использовать

- Поиск плагинов выявил плагины, соответствующие тому, что пользователь пытается сделать, и вы хотите предложить их к установке.

## Активация

- Только когда подключён клиент Remote Control или сессия выполняется в управляемой облачной среде.
- Отключён в корпоративных конфигурациях с HIPAA.
- Не в brief-режиме.

## Параметры

- `contextLabel` (string, обязательный): короткий заголовок, привязывающий предложение к запросу пользователя (максимум 128 символов).
- `plugins` (array, обязательный): плагины из результатов `SearchPlugins` — 1–16 записей, каждая содержит:
  - `pluginId` (string, обязательный)
  - `pluginName` (string, обязательный)
  - `description` (string, обязательный)
  - `skills` (array, необязательный): до 32 записей `{name, description?}`, описывающих навыки плагина.

## Примеры

### Пример 1: предложить подходящий плагин

```
SuggestPluginInstall(
  contextLabel="For reviewing pull requests",
  plugins=[{pluginId="pr-toolkit", pluginName="PR Toolkit", description="Review helpers"}]
)
```

Карточка рендерится для пользователя; включение плагина происходит вне этого инструмента. Вызовите `ListPlugins` при последующем обращении, чтобы узнать, что было фактически установлено.

## Примечания

- Включайте только плагины, пришедшие из результатов поиска — никогда не изобретайте записи плагинов.
