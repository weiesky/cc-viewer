# ReadMcpResourceDir

Перечисляет записи ресурса каталогового типа, предоставляемого подключённым MCP-сервером, по его URI.

## Когда использовать

- MCP-сервер организует ресурсы иерархически, и вам нужно перечислить один уровень этой иерархии.
- Вы хотите осмотреться перед чтением отдельных ресурсов через `ReadMcpResource`.

## Активация

- Всегда включён, но не показывается в списке инструментов модели — предназначен для использования тонким клиентом / сайдкаром.

## Параметры

- `server` (string, обязательный): имя MCP-сервера.
- `uri` (string, обязательный): URI ресурса-каталога для перечисления.

## Примеры

### Пример 1: перечислить каталог ресурсов

```
ReadMcpResourceDir(server="filesystem", uri="file:///project/src/")
```

Возвращает дочерние записи, которые сервер предоставляет под этим URI каталога.

## Примечания

- Поддерживается только серверами, которые моделируют свои ресурсы как каталоги; серверы с плоской структурой вернут ошибку или пустой листинг — откатывайтесь на `ListMcpResources`.
- Комбинируйте с `ReadMcpResource`, чтобы углубляться в записи, которые выглядят релевантными.
