# ReadMcpResource

Читає один ресурс, який надає підключений MCP-сервер (Model Context Protocol), за його URI.

## Коли використовувати

- MCP-сервер оголошує ресурс (файл, запис, документ), вміст якого вам потрібен у контексті.
- У вас є конкретний URI ресурсу — з `ListMcpResources`, з документації сервера чи з попереднього результату інструмента.

## Активація

- Завжди увімкнено, але не показується в списку інструментів моделі — призначено для використання thin-client / sidecar.

## Параметри

- `server` (string, обовʼязковий): Імʼя MCP-сервера.
- `uri` (string, обовʼязковий): URI ресурсу для читання.

## Приклади

### Приклад 1: Читання ресурсу сервера за URI

```
ReadMcpResource(server="github", uri="file:///repo/docs/architecture.md")
```

Повертає вміст ресурсу в тому вигляді, як його надає MCP-сервер `github`.

## Примітки

- Спершу використайте `ListMcpResources`, якщо не знаєте, які ресурси надає сервер; для переліків каталогового типу використовуйте `ReadMcpResourceDir`.
- Схема URI є специфічною для сервера (`file://`, `https://`, власні схеми) — перевірте, що оголошує цільовий сервер.
