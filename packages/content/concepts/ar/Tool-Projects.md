# Projects

يدير مستندات المشروع في قاعدة معرفة مشروع المستخدم على Claude: قراءة وبحث وكتابة وحذف المستندات، أو جلب معلومات المشروع.

## متى يُستخدم

- حفظ مستند (مخرج أو ملاحظات أو مادة مرجعية) في مشروع المستخدم حتى يبقى بعد الجلسة.
- قراءة مستندات المشروع الحالية أو البحث فيها لتأسيس المهمة الحالية على سياق سابق.
- رفع ملف محلي إلى المشروع دون تحميل محتواه في السياق.
- إزالة مستند مشروع قديم.

## المعاملات

- `method` (سلسلة، مطلوب): واحدة من `project_info` أو `project_read` أو `project_search` أو `project_write` أو `project_delete`.
- `path` (سلسلة، اختياري): لأجل `project_read`/`project_write`/`project_delete`: مسار المستند. ولأجل `project_write`: المسار الموجود يُستبدل في مكانه؛ واسم الملف المجرد الجديد (بدون "/") يُنسَب إلى `claude/<name>`.
- `content` (سلسلة، اختياري): لأجل `project_write`: نص المستند المكتوب مباشرة. متنافٍ مع `local_path`.
- `local_path` (سلسلة، اختياري): لأجل `project_write`: ملف داخل دليل العمل لرفعه — لا يدخل محتواه سياقك أبداً. متنافٍ مع `content`.
- `present_to_user` (منطقي، اختياري): لأجل `project_write`: علِّم هذا المستند بوصفه المخرج الذي يحتاج المستخدم إلى رؤيته. الافتراضي false؛ اتركه غير مضبوط للحفظات الروتينية والكتابات المجمعة.
- `query` (سلسلة، اختياري): لأجل `project_search`: استعلام قاعدة المعرفة.
- `n` (عدد، اختياري): لأجل `project_search`: عدد النتائج (الافتراضي 5).

## أمثلة

### مثال 1: كتابة المخرج في المشروع

```
Projects(
  method="project_write",
  path="claude/migration-plan.md",
  local_path="./migration-plan.md",
  present_to_user=true
)
```

يرفع الملف المحلي دون سحب محتواه إلى السياق، ويعلّمه بوصفه مخرج المستخدم.

### مثال 2: البحث في قاعدة المعرفة

```
Projects(method="project_search", query="authentication refresh tokens", n=5)
```

## ملاحظات

- `content` للنص الذي تؤلفه مباشرة؛ و`local_path` لأي شيء موجود على القرص بالفعل — لا تخلط بينهما أبداً.
- استخدم `present_to_user=true` باعتدال: فقط للمستند الوحيد الذي طلبه المستخدم أو يجب أن يتصرف بناءً عليه.
