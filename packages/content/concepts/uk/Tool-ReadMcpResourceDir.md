# ReadMcpResourceDir

Перелічує записи ресурсу каталогового типу, який надає підключений MCP-сервер, за його URI.

## Коли використовувати

- MCP-сервер організовує ресурси ієрархічно, і вам потрібно перелічити один рівень цієї ієрархії.
- Ви хочете оглянутися перед читанням окремих ресурсів за допомогою `ReadMcpResource`.

## Активація

- Завжди увімкнено, але не показується в списку інструментів моделі — призначено для використання thin-client / sidecar.

## Параметри

- `server` (string, обовʼязковий): Імʼя MCP-сервера.
- `uri` (string, обовʼязковий): URI каталогового ресурсу для переліку.

## Приклади

### Приклад 1: Перелік каталогу ресурсів

```
ReadMcpResourceDir(server="filesystem", uri="file:///project/src/")
```

Повертає дочірні записи, які сервер надає під цим URI каталогу.

## Примітки

- Це підтримують лише сервери, які моделюють свої ресурси як каталоги; пласкі сервери повернуть помилку або порожній перелік — відступіть до `ListMcpResources`.
- Поєднуйте з `ReadMcpResource`, щоб заглибитися в записи, які виглядають релевантними.
