# ListSkills

แสดงรายการ skill ของ claude.ai ที่ผู้ใช้เปิดใช้งานอยู่ กรองด้วย keyword ได้ (ไม่บังคับ)

## เมื่อใดควรใช้

- คุณต้องการรายการ skill ที่เปิดใช้งานอยู่ชุดเดียวที่น่าเชื่อถือ — ก่อน invoke skill หนึ่ง หรือเพื่อยืนยันสิ่งที่การ์ด `SuggestSkills` เพิ่มเข้าไป
- ผู้ใช้ถามว่าพวกเขามี skill อะไรบ้าง

## การเปิดใช้งาน

- ต้องใช้สิทธิ์การเข้าถึง plugin registry
- ปิดใช้งานในสภาพแวดล้อม HIPAA
- พร้อมใช้งานเสมอในเซสชันระยะไกล

## พารามิเตอร์

- `keywords` (array of strings, optional): กรองรายการ — ไม่เกิน 8 รายการ แต่ละรายการ 1–64 ตัวอักษร ละเว้นเพื่อแสดงทั้งหมด

## ตัวอย่าง

### ตัวอย่างที่ 1: แสดงรายการ skill ที่เปิดใช้งาน

```
ListSkills()
```

### ตัวอย่างที่ 2: กรองด้วย keyword

```
ListSkills(keywords=["review"])
```

## หมายเหตุ

- หาก catalog เข้าถึงไม่ได้ (forbidden) เครื่องมือจะลดระดับเป็นรายการว่างพร้อมคำเตือนแทนที่จะล้มเหลว
- เครื่องมือนี้แสดงรายการ skill ที่ *เปิดใช้งานแล้ว* ส่วน `SuggestSkills` ใช้เพื่อผุด skill ที่ผู้ใช้เพิ่มได้
