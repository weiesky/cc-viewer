# ListConnectors

ユーザーの claude.ai 組織にインストールされている MCP コネクタを一覧表示します。オプションでキーワードで絞り込めます。

## 使用タイミング

- 新しいコネクタを提案する前に、どのコネクタがすでにインストールされているかを知る必要がある場合。
- ユーザーが自分の組織にどのような統合があるかを尋ねた場合。

## 有効化

- ファーストパーティ API 上のリモート (claude.ai) セッションでのみ利用可能です。

## パラメータ

- `keywords` (array of strings, optional): 一覧の絞り込み — 最大 8 項目、各 1〜64 文字。省略するとすべてを一覧表示します。

## 例

### 例 1: インストール済みコネクタをすべて一覧表示

```
ListConnectors()
```

### 例 2: キーワードで絞り込む

```
ListConnectors(keywords=["github"])
```

## 注意事項

- 完全な「検索して有効化」フローには、`SearchMcpRegistry` (発見) と `SuggestConnectors` (詳細) を組み合わせてください。
