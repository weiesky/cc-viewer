# ListAgents

Перечисляет агентов, которым можно отправлять `SendMessage`: внутрипроцессных подагентов, которых вы запустили, другие локальные сессии Claude на этой машине, ваши облачные сессии (когда у этой сессии есть облачный доступ) и — когда подключён Remote Control — остальные сессии вашего аккаунта. Каждая строка помечена своим типом.

## Когда использовать

- Вам нужно точное имя пир-сессии или подагента перед отправкой ему сообщения.
- Вы хотите увидеть, какие сессии сейчас достижимы из этой.

## Активация

- Требует Claude Code 2.1.224+ и межсессионный обмен сообщениями (серверный фича-флаг, выключен по умолчанию).
- Межсессионный обмен сообщениями недоступен на Amazon Bedrock, Claude Platform on AWS, Google Cloud Agent Platform и Microsoft Foundry.
- Выключен, когда задано `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`, `DISABLE_TELEMETRY`, `DO_NOT_TRACK` или `DISABLE_GROWTHBOOK`.
- Принудительное включение через `CLAUDE_CODE_HARBOR_KITE=1`.

## Параметры

- `channel` (string, необязательный): недоступен в этой сборке; оставьте незаданным.
- `q` (string, необязательный): недоступен в этой сборке; оставьте незаданным.

## Примеры

### Пример 1: перечислить достижимых агентов

```
ListAgents()
```

Каждая строка печатает имя — это имя и есть адрес. Отправляйте через `SendMessage({to: "<name>", message: "..."})`, копируя имя в точности как напечатано. Добавляйте ` [ref]` из строки, только когда голое имя неоднозначно (две строки используют одно имя, или ошибка просит устранить неоднозначность).

## Примечания

- Только для чтения и безопасен при параллельных вызовах.
- Облачная сессия получает ваше сообщение, но пока не может ответить — читайте её ответ в её собственном транскрипте.
