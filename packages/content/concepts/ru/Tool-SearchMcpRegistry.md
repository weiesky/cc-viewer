# SearchMcpRegistry

Ищет по реестру MCP-коннекторов по ключевым словам, чтобы обнаружить коннекторы, которые могут помочь завершить задачу.

## Когда использовать

- Задача выиграет от внешнего сервиса (базы данных, трекера задач, SaaS API), и вы хотите проверить, существует ли для него MCP-коннектор.
- Пользователь называет продукт и просит подключить его — ищите в реестре подходящий коннектор.

## Активация

- Доступен только в удалённых (claude.ai) сессиях на собственном API.

## Параметры

- `keywords` (array of strings, обязательный): ключевые фразы, описывающие намерение пользователя или названный продукт. 1–8 элементов, каждый 1–64 символа.

## Примеры

### Пример 1: найти коннектор для названного продукта

```
SearchMcpRegistry(keywords=["linear", "issue tracker"])
```

Возвращает записи реестра, чьи коннекторы совпадают с ключевыми словами. Полные детали коннектора разрешайте через `SuggestConnectors`.

## Примечания

- Только для чтения и безопасен при параллельных вызовах; результаты ограничены по размеру.
- Поиск ничего не устанавливает — это чистое обнаружение.
