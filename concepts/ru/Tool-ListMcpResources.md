# ListMcpResources

Перечисляет ресурсы, предоставляемые подключёнными MCP-серверами, опционально с фильтром по одному серверу.

## Когда использовать

- Вам нужно узнать, какие ресурсы (файлы, записи, документы) предлагает MCP-сервер, прежде чем читать их.
- Вы хотите обзор всех ресурсов по всем подключённым серверам.

## Параметры

- `server` (string, необязательный): имя сервера для фильтрации ресурсов. Опустите, чтобы перечислить ресурсы всех подключённых серверов.

## Примеры

### Пример 1: перечислить всё

```
ListMcpResources()
```

### Пример 2: перечислить ресурсы одного сервера

```
ListMcpResources(server="github")
```

## Примечания

- Это шаг обнаружения: подавайте интересные URI в `ReadMcpResource` (одиночный ресурс) или `ReadMcpResourceDir` (листинги каталогов).
- Серверы подключаются и отключаются в течение жизни сессии; перечислите заново, если сервер только что добавили.
