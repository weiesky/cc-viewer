# ListSkills

Перечисляет включённые у пользователя навыки claude.ai, опционально с фильтром по ключевому слову.

## Когда использовать

- Вам нужен авторитетный список навыков, включённых сейчас — перед вызовом одного из них или чтобы подтвердить, что добавила карточка `SuggestSkills`.
- Пользователь спрашивает, какие у него навыки.

## Параметры

- `keywords` (array of strings, необязательный): фильтрация списка — до 8 элементов, каждый 1–64 символа. Опустите, чтобы перечислить всё.

## Примеры

### Пример 1: перечислить включённые навыки

```
ListSkills()
```

### Пример 2: фильтр по ключевому слову

```
ListSkills(keywords=["review"])
```

## Примечания

- Если каталог недостижим (forbidden), инструмент деградирует до пустого списка с предупреждением, а не падает.
- Это список *включённых* навыков; используйте `SuggestSkills`, чтобы показать навыки, которые пользователь мог бы добавить.
