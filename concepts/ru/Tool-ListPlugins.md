# ListPlugins

Перечисляет включённые у пользователя плагины claude.ai, опционально с фильтром по ключевому слову.

## Когда использовать

- Вам нужно знать, какие плагины уже включены — например, чтобы подтвердить, что установилось после карточки `SuggestPluginInstall`.
- Пользователь спрашивает, какие у него плагины.

## Параметры

- `keywords` (array of strings, необязательный): фильтрация списка — до 8 элементов, каждый 1–64 символа. Опустите, чтобы перечислить всё.

## Примеры

### Пример 1: перечислить включённые плагины

```
ListPlugins()
```

### Пример 2: фильтр по ключевому слову

```
ListPlugins(keywords=["figma"])
```

## Примечания

- Если каталог плагинов недостижим (forbidden), инструмент деградирует до пустого списка с предупреждением, а не падает.
- Доступность зависит от типа сессии и внедрения функции.
