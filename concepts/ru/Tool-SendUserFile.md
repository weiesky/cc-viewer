# SendUserFile

Отправляет пользователю один или несколько файлов — сгенерированные артефакты, скриншоты, отчёты — с контролем над тем, как клиент их представит.

## Когда использовать

- Вы создали файл, который нужен пользователю (отчёт, изображение, HTML-страница), и хотите его показать, а не просто упомянуть путь.
- Ответ с вложением (`status="normal"`) или проактивный показ того, о чём пользователь не просил, но что ему нужно увидеть сейчас (`status="proactive"`).

## Параметры

- `files` (array of strings, обязательный): пути файлов (абсолютные или относительно cwd) для отправки пользователю. Всегда передавайте массив, даже для одного файла.
- `caption` (string, необязательный): короткая подпись к файлу(-ам).
- `status` (string, обязательный): `proactive`, когда показываете файл, о котором пользователь не просил и который ему нужно увидеть сейчас — сгенерированный артефакт, завершённый отчёт; `normal`, когда отвечаете на то, что пользователь только что сказал.
- `display` (string, необязательный): `render` открывает файл inline в боковой панели (HTML, SVG, Mermaid, изображения, PDF); `attach` показывает только карточку скачивания (результаты, которые пользователь сохранит и откроет в другом месте). Опустите, чтобы клиент решал по типу файла.

## Примеры

### Пример 1: доставить сгенерированный отчёт

```
SendUserFile(
  files=["./out/weekly-report.html"],
  caption="Weekly usage report",
  status="proactive",
  display="render"
)
```

## Примечания

- Требует, чтобы сессия разрешала отправку файлов (возможность, открываемая настройками/фича-флагами); не предлагается в brief-режиме.
- Выбирайте `display="attach"` для файлов, которые пользователь сохраняет и открывает в другом приложении; `render` — для всего, что он должен посмотреть немедленно.
