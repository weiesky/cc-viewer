# SendFeedback

Отправляет структурированный отзыв о Claude Code в Anthropic — баг-репорты, идеи функций или отсутствующие возможности — не покидая сессию.

## Когда использовать

- Пользователь просит сообщить о баге или отправить отзыв о самом Claude Code.
- Вы столкнулись с явным дефектом продукта (сломанная команда, неправильное поведение, краш), о котором стоит сообщить.
- Пользователь описывает функцию, которую хотел бы видеть (идею или отсутствующую возможность).

## Параметры

- `type` (string, обязательный): одно из `bug`, `idea`, `missing_capability`.
- `title` (string, обязательный): короткое, конкретное однострочное резюме проблемы.
- `details` (string, обязательный): маркированные пункты с метками, по порядку: **What happened:** (наблюдаемое против ожидаемого, точный текст ошибки, если он короткий); **What the user said:** (цитата или "User didn't comment; observed by the model."); **Repro:** (минимальные шаги); **Evidence:** (ID запросов, временные метки, пути, версии — опустить, если нет); опционально финальный **Cause:** только если подтверждён в сессии. Одна-три строки на пункт; без повествовательных абзацев, без спекуляций, без секретов.
- `area` (string, необязательный): короткий тег, называющий часть Claude Code, к которой это относится (например, "hooks config", "/help", "file editing"). Оставьте пустым, если неясно.
- `failure_mode` (string, необязательный): для отчётов о поведении модели — ближайший режим сбоя (например, `instruction_following`, `repetition_and_looping`, `context_and_memory`, `stopping_short` или `other`). Опускайте только когда отчёт — чисто продуктовый/инструментальный баг.
- `task_category` (string, необязательный): чем занималась сессия в момент проблемы: `code_edit`, `debug`, `explain`, `plan`, `shell`, `search`, `review` или `other`.

## Примеры

### Пример 1: сообщить о продуктовом баге

```
SendFeedback(
  type="bug",
  title="/export truncates the last message",
  details="**What happened:** exported transcript is missing the final assistant message.\n**What the user said:** \"the last reply never shows up in the file\".\n**Repro:** run /export after any multi-turn session.\n**Evidence:** v2.1.233, macOS.",
  area="/export",
  task_category="other"
)
```

## Примечания

- Никогда не включайте секреты, токены или приватные данные пользователя в `details`.
- Цитируйте слова пользователя, когда они доступны; иначе укажите, что модель наблюдала проблему.
- Держите отчёт фактическим — спекуляции о первопричине допустимы только в `**Cause:**` и только когда подтверждены в сессии.
