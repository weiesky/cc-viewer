# SendFile

Отправляет один или несколько файлов в другую сессию Claude Code — пир-сессию из списка `ListAgents` или явный адрес сессии.

## Когда использовать

- Пир-сессии нужен файл из вашей рабочей директории (отчёт, патч, фикстура), чтобы продолжить собственную задачу.
- Вы координируете работу между сессиями и хотите передавать артефакты, а не только текст (для текста используйте `SendMessage`).

## Параметры

- `to` (string, обязательный): получатель — имя пир-сессии из `ListAgents` или явный адрес `uds:<socket>` / `bridge:<session id>`.
- `files` (array of strings, обязательный): пути файлов (абсолютные или относительно cwd) для отправки. Всегда передавайте массив, даже для одного файла. 1–16 файлов, максимум 30 MiB каждый.
- `message` (string, необязательный): короткое сообщение, доставляемое вместе с файлами.

## Примеры

### Пример 1: отправить отчёт в пир-сессию

```
SendFile(
  to="teammate-a",
  files=["./dist/report.html"],
  message="The analysis you asked for"
)
```

## Примечания

- Межсессионная передача файлов должна быть доступна в сессии; когда это не так, валидация завершается ошибкой "Cross-session file transfer is not available in this session."
- Передачи на удалённые машины могут требовать дополнительного одобрения.
- Чтение содержимого файлов — часть отправки; отклоняется, если чтение файлов запрещено правилами разрешений.
