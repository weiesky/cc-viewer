# ProposeGoal

Предлагает проверяемую цель завершения сессии. Цель показывается пользователю в диалоге утверждения (по умолчанию) и, будучи установленной, направляет остаток разговора к проверяемому результату.

## Когда использовать

- У сессии есть конкретное конечное состояние, которое оценщик мог бы проверить по разговору (например, "all tests in test/auth pass").
- Вы хотите явного подтверждения пользователем того, что значит «готово», перед существенной работой.
- Слова пользователя уже сформулировали результат, и вы хотите зафиксировать его как цель сессии.

## Параметры

- `condition` (string, обязательный): условие завершения, записанное так, чтобы отдельный оценщик мог проверить его по разговору (например, "all tests in test/auth pass (bun test exits 0)"). Не более 500 символов — пользователь должен иметь возможность прочитать условие целиком в диалоге утверждения.
- `ask_user` (boolean, необязательный): спрашивать ли пользователя об утверждении до установки цели. По умолчанию true (показывается диалог утверждения). Задавайте false ТОЛЬКО когда собственные слова пользователя в этом разговоре назвали этот результат как желаемый; тогда цель устанавливается напрямую с видимым уведомлением, а пользователь может очистить её через `/goal clear`.

## Примеры

### Пример 1: предложить цель, подкреплённую тестами

```
ProposeGoal(condition="npm run test exits 0 with the new catalog cases included")
```

Пользователь видит условие в диалоге утверждения и может принять, отредактировать или отклонить его.

### Пример 2: принять сформулированный пользователем результат напрямую

```
ProposeGoal(condition="the login form validates email format and shows an inline error", ask_user=false)
```

Допустимо только потому, что пользователь явно назвал этот результат ранее в разговоре.

## Примечания

- Держите `condition` коротким и объективно проверяемым — размытые цели ("make it better") лишают инструмент смысла.
- `ask_user=false` строго ограничен результатами, которые пользователь сам назвал; всё остальное должно проходить через диалог утверждения.
