# SendUserMessage

Отправляет сообщение пользователю — основной видимый канал вывода в сессиях в стиле brief. Также известен под устаревшим псевдонимом `Brief`.

## Когда использовать

- Ответ на то, что пользователь только что сказал (`status="normal"`).
- Проактивный показ того, о чём пользователь не просил и что ему нужно увидеть сейчас — задача, завершившаяся пока его нет, блокер, в который вы упёрлись, незапрошенное обновление статуса (`status="proactive"`).

## Параметры

В brief-режиме:

- `message` (string, обязательный): сообщение для пользователя. Поддерживает markdown-форматирование.
- `attachments` (array, необязательный): вложения, показываемые рядом с сообщением. Каждая запись — либо путь к файлу (абсолютный или относительно cwd) для локально читаемого файла, либо заранее разрешённый объект `{file_uuid, file_name, size, is_image}`, полученный от инструмента устройства, такого как `attach_file`.
- `status` (string, обязательный): `proactive` для незапрошенных обновлений, которые нужны пользователю сейчас; `normal` при ответе пользователю.

В сборках без brief доступен только `message`.

## Примеры

### Пример 1: проактивное уведомление о завершении

```
SendUserMessage(
  message="The migration finished — 42 files updated, tests green.",
  status="proactive"
)
```

## Примечания

- Включён только в brief-режиме или через соответствующее внедрение функции; большинство интерактивных CLI-сессий вместо этого говорят с пользователем напрямую.
- Используйте `proactive` экономно — он предназначен для вещей, которые действительно требуют внимания пользователя прямо сейчас.
