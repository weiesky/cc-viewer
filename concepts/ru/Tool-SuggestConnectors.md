# SuggestConnectors

Разрешает полные полезные данные (payload) коннекторов для значений `directoryUuid`, возвращённых `SearchMcpRegistry`, чтобы пользователю можно было предложить конкретные коннекторы для включения.

## Когда использовать

- После того как `SearchMcpRegistry` вернул кандидатов-коннекторы, чтобы получить их полные детали для представления.

## Активация

- Доступен только в удалённых (claude.ai) сессиях на собственном API.

## Параметры

- `uuids` (array of strings, обязательный): значения `directoryUuid` или `server_id` для разрешения. 1–32 элемента, каждый 1–64 символа.

## Примеры

### Пример 1: разрешить два попадания из реестра

```
SuggestConnectors(uuids=["d290f1ee-6c54-4b01-90e6-d701748f0851", "a1b2c3d4-0000-4000-8000-abcdefabcdef"])
```

## Примечания

- Никогда не угадывайте UUID — разрешайте только идентификаторы, пришедшие из `SearchMcpRegistry`.
- Инструмент сам ничего не подключает; включение коннектора происходит вне этого инструмента.
