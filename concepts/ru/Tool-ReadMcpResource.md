# ReadMcpResource

Читает один ресурс, предоставляемый подключённым MCP-сервером (Model Context Protocol), по его URI.

## Когда использовать

- MCP-сервер рекламирует ресурс (файл, запись, документ), чьё содержимое вам нужно в контексте.
- У вас есть конкретный URI ресурса — из `ListMcpResources`, из документации сервера или из предыдущего результата инструмента.

## Параметры

- `server` (string, обязательный): имя MCP-сервера.
- `uri` (string, обязательный): URI ресурса для чтения.

## Примеры

### Пример 1: прочитать ресурс сервера по URI

```
ReadMcpResource(server="github", uri="file:///repo/docs/architecture.md")
```

Возвращает содержимое ресурса в том виде, как его предоставляет MCP-сервер `github`.

## Примечания

- Сначала используйте `ListMcpResources`, если не знаете, какие ресурсы предоставляет сервер; для листингов каталогового типа используйте `ReadMcpResourceDir`.
- Схема URI специфична для сервера (`file://`, `https://`, пользовательские схемы) — проверьте, что рекламирует целевой сервер.
