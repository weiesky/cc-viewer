# ListConnectors

Перечисляет MCP-коннекторы, установленные для организации пользователя на claude.ai, опционально с фильтром по ключевому слову.

## Когда использовать

- Вам нужно знать, какие коннекторы уже установлены, прежде чем предлагать новые.
- Пользователь спрашивает, какие интеграции есть у его организации.

## Параметры

- `keywords` (array of strings, необязательный): фильтрация списка — до 8 элементов, каждый 1–64 символа. Опустите, чтобы перечислить всё.

## Примеры

### Пример 1: перечислить все установленные коннекторы

```
ListConnectors()
```

### Пример 2: фильтр по ключевому слову

```
ListConnectors(keywords=["github"])
```

## Примечания

- Доступно только в удалённых (claude.ai) сессиях на собственном API.
- Сочетайте с `SearchMcpRegistry` (обнаружение) и `SuggestConnectors` (детали) для полного потока «найти и включить».
