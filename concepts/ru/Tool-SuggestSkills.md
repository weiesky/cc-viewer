# SuggestSkills

Рендерит карточку автономных навыков, которые пользователь может добавить (навыки, ещё не включённые), на основе ключевых слов темы.

## Когда использовать

- Запрос пользователя соответствует навыкам, которые у него не включены (`trigger="user_asked"`, когда он спросил, `trigger="proactive"`, когда вы предлагаете без запроса).

## Активация

- Только когда подключён клиент Remote Control или сессия выполняется в управляемой облачной среде.
- Отключён в корпоративных конфигурациях с HIPAA.
- Не в brief-режиме.

## Параметры

- `keywords` (array of strings, обязательный): ключевые слова темы из запроса пользователя. 1–8 элементов, каждый 1–64 символа.
- `contextLabel` (string, необязательный): короткая метка, привязывающая предложение к запросу (максимум 128 символов).
- `trigger` (string, необязательный): как началось это предложение — `user_asked` или `proactive`.

## Примеры

### Пример 1: предложить навыки по теме

```
SuggestSkills(keywords=["data visualization", "charts"], contextLabel="For building the dashboard", trigger="user_asked")
```

Уже включённые навыки отфильтровываются из результата.

## Примечания

- Рендерит только карточку-предложение — добавление навыка происходит вне этого инструмента; вызовите `ListSkills` после, чтобы подтвердить.
