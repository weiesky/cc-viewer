# ListConnectors

Перелічує MCP-конектори, встановлені для організації користувача на claude.ai, опціонально відфільтровані за ключовим словом.

## Коли використовувати

- Вам потрібно знати, які конектори вже встановлено, перш ніж пропонувати нові.
- Користувач питає, які інтеграції має його організація.

## Параметри

- `keywords` (array of strings, необовʼязковий): Фільтр списку — до 8 елементів, кожен 1–64 символи. Пропустіть, щоб перелічити все.

## Приклади

### Приклад 1: Перелік усіх встановлених конекторів

```
ListConnectors()
```

### Приклад 2: Фільтрація за ключовим словом

```
ListConnectors(keywords=["github"])
```

## Примітки

- Доступний лише у віддалених (claude.ai) сесіях на офіційному API.
- Поєднуйте з `SearchMcpRegistry` (виявлення) та `SuggestConnectors` (деталі) для повного потоку «знайти й увімкнути».
