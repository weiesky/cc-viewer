# ListSkills

Перелічує увімкнені навички claude.ai користувача, опціонально відфільтровані за ключовим словом.

## Коли використовувати

- Вам потрібен авторитетний список навичок, увімкнених наразі — перед викликом однієї з них або щоб підтвердити, що додала картка `SuggestSkills`.
- Користувач питає, які навички він має.

## Активація

- Потребує дозволу на доступ до реєстру плагінів.
- Вимкнено в середовищах HIPAA.
- Завжди доступно у віддалених сесіях.

## Параметри

- `keywords` (array of strings, необовʼязковий): Фільтр списку — до 8 елементів, кожен 1–64 символи. Пропустіть, щоб перелічити все.

## Приклади

### Приклад 1: Перелік увімкнених навичок

```
ListSkills()
```

### Приклад 2: Фільтрація за ключовим словом

```
ListSkills(keywords=["review"])
```

## Примітки

- Якщо каталог недосяжний (заборонено), інструмент деградує до порожнього списку з попередженням замість помилки.
- Це перелічує *увімкнені* навички; використовуйте `SuggestSkills`, щоб показати навички, які користувач міг би додати.
