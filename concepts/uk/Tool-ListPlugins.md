# ListPlugins

Перелічує увімкнені плагіни claude.ai користувача, опціонально відфільтровані за ключовим словом.

## Коли використовувати

- Вам потрібно знати, які плагіни вже увімкнено — наприклад, щоб підтвердити, що було встановлено після картки `SuggestPluginInstall`.
- Користувач питає, які плагіни він має.

## Параметри

- `keywords` (array of strings, необовʼязковий): Фільтр списку — до 8 елементів, кожен 1–64 символи. Пропустіть, щоб перелічити все.

## Приклади

### Приклад 1: Перелік увімкнених плагінів

```
ListPlugins()
```

### Приклад 2: Фільтрація за ключовим словом

```
ListPlugins(keywords=["figma"])
```

## Примітки

- Якщо каталог плагінів недосяжний (заборонено), інструмент деградує до порожнього списку з попередженням замість помилки.
- Доступність залежить від типу сесії та поступового впровадження функцій.
