# TodoWrite

Записує структурований todo-список для поточної сесії, замінюючи попередній список. Кожен елемент містить свій текст, статус і форму теперішнього тривалого часу, яка показується в індикаторах прогресу.

## Коли використовувати

- Завдання має кілька окремих кроків, і відстеження їх допомагає вам (і користувачу) бачити прогрес.
- Користувач явно просить todo-список.
- Ви хочете позначити рівно один елемент як «у процесі», поки решта залишаються очікуваними або завершеними.

## Активація

- Застарілий інструмент: вимкнено за замовчуванням у сесіях, які пропонують інструменти завдань (`TaskCreate`, `TaskUpdate`, `TaskList`).
- Увімкніть його знову через `CLAUDE_CODE_ENABLE_TASKS=0`.

## Параметри

- `todos` (array, обовʼязковий): Повний оновлений todo-список. Кожен запис має:
  - `content` (string): Опис завдання.
  - `status` (string): Одне з `pending`, `in_progress`, `completed`.
  - `activeForm` (string): Текст у теперішньому тривалому часі, який показується, поки елемент виконується (наприклад, "Running tests").

## Приклади

### Приклад 1: Відстеження зміни з трьох кроків

```
TodoWrite(
  todos=[
    {content="Update the parser", status="in_progress", activeForm="Updating the parser"},
    {content="Add unit tests", status="pending", activeForm="Adding unit tests"},
    {content="Run the full test suite", status="pending", activeForm="Running the full test suite"}
  ]
)
```

Весь список перезаписується при кожному виклику — завжди включайте всі елементи, а не лише ті, що змінилися.

## Примітки

- Список повністю замінюється при кожному виклику; щоб оновити один елемент, повторно надішліть усі елементи з новим статусом.
- Тримайте рівно один елемент у статусі `in_progress` одночасно.
- У сесіях, де увімкнено структуровані інструменти завдань (`TaskCreate`/`TaskUpdate`/`TaskList`), оболонка може запропонувати їх замість `TodoWrite` — віддавайте перевагу тому набору інструментів, який оголошено.
