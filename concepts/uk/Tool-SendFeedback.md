# SendFeedback

Надсилає структурований відгук про Claude Code до Anthropic — звіти про помилки, ідеї функцій чи відсутні можливості — не виходячи з сесії.

## Коли використовувати

- Користувач просить повідомити про помилку чи надіслати відгук про сам Claude Code.
- Ви натрапили на явний дефект продукту (зламана команда, неправильна поведінка, збій), про який варто повідомити.
- Користувач описує функцію, яку хотів би бачити (ідею чи відсутню можливість).

## Параметри

- `type` (string, обовʼязковий): Одне з `bug`, `idea`, `missing_capability`.
- `title` (string, обовʼязковий): Коротке, конкретне однорядкове резюме проблеми.
- `details` (string, обовʼязковий): Марковані пункти з мітками, по порядку: **What happened:** (фактична поведінка проти очікуваної, точний текст помилки, якщо короткий); **What the user said:** (цитата, або "User didn't comment; observed by the model."); **Repro:** (мінімальні кроки); **Evidence:** (ідентифікатори запитів, часові мітки, шляхи, версії — пропустіть, якщо немає); опціонально фінальний **Cause:** лише якщо підтверджено в сесії. Один-три рядки на пункт; без наративних абзаців, без спекуляцій, без секретів.
- `area` (string, необовʼязковий): Короткий тег, що називає частину Claude Code, якої це стосується (наприклад, "hooks config", "/help", "file editing"). Залиште порожнім, якщо незрозуміло.
- `failure_mode` (string, необовʼязковий): Для звітів про поведінку моделі — найближчий режим збою (наприклад, `instruction_following`, `repetition_and_looping`, `context_and_memory`, `stopping_short` або `other`). Пропускайте лише тоді, коли звіт є чистою помилкою продукту/інструмента.
- `task_category` (string, необовʼязковий): Що робила сесія, коли виникла проблема: `code_edit`, `debug`, `explain`, `plan`, `shell`, `search`, `review` або `other`.

## Приклади

### Приклад 1: Звіт про помилку продукту

```
SendFeedback(
  type="bug",
  title="/export truncates the last message",
  details="**What happened:** exported transcript is missing the final assistant message.\n**What the user said:** \"the last reply never shows up in the file\".\n**Repro:** run /export after any multi-turn session.\n**Evidence:** v2.1.233, macOS.",
  area="/export",
  task_category="other"
)
```

## Примітки

- Ніколи не включайте секрети, токени чи приватні дані користувача у `details`.
- Цитуйте слова користувача, коли вони доступні; інакше зазначте, що проблему спостерігала модель.
- Тримайте звіт фактичним — спекуляції про першопричину належать до `**Cause:**` лише тоді, коли підтверджені в сесії.
