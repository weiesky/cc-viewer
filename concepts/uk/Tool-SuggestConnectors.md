# SuggestConnectors

Розвʼязує повні payload-и конекторів для значень `directoryUuid`, повернутих `SearchMcpRegistry`, щоб користувачу можна було запропонувати конкретні конектори для увімкнення.

## Коли використовувати

- Після того, як `SearchMcpRegistry` повернув конектори-кандидати, — щоб отримати їхні повні деталі для представлення.

## Активація

- Доступний лише у віддалених (claude.ai) сесіях на офіційному API.

## Параметри

- `uuids` (array of strings, обовʼязковий): Значення `directoryUuid` або `server_id` для розвʼязання. 1–32 елементи, кожен 1–64 символи.

## Приклади

### Приклад 1: Розвʼязання двох збігів з реєстру

```
SuggestConnectors(uuids=["d290f1ee-6c54-4b01-90e6-d701748f0851", "a1b2c3d4-0000-4000-8000-abcdefabcdef"])
```

## Примітки

- Ніколи не вгадуйте UUID — розвʼязуйте лише ідентифікатори, що надійшли від `SearchMcpRegistry`.
- Інструмент сам нічого не підключає; увімкнення конектора відбувається поза межами цього інструмента.
