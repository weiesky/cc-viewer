# ReadNotifications

Читає сповіщення, поставлені в чергу для асистента в поточній сесії — активність GitHub у підписаних PR (`github_webhook`), спрацювання запланованих тригерів (`trigger_fire`) та повідомлення, що надходять з інших сесій Claude (`mcp_send_message`).

## Коли використовувати

- Вас повідомили, що щось сталося — підписаний PR оновився, запланований тригер спрацював, інша сесія надіслала вам повідомлення — і вам потрібне фактичне корисне навантаження.
- Спустошення накопиченої черги: великі партії повертаються частинами, тож продовжуйте виклики, поки результат не повідомить про 0 `remaining`.

## Параметри

Цей інструмент не приймає параметрів.

## Приклади

### Приклад 1: Спорожнити очікувані сповіщення

```
ReadNotifications()
```

Повертає сповіщення з черги, найстаріші спершу. Результат містить лічильник `remaining` — кількість сповіщень, що лишаються в черзі після цього спустошення, — викличте інструмент ще раз, щоб їх прочитати.

## Примітки

- Спустошення мають обмеження за розміром: наступний виклик повертає решту ТІЄЇ Ж САМОЇ черги (плюс усе, що щойно надійшло), а не лише нові надходження. Повторюйте виклики, поки `remaining` не дорівнюватиме 0.
- Сповіщення походять від вебхуків GitHub на підписаних PR, запланованих тригерів та повідомлень з інших сесій Claude; у поточній версії параметра фільтрації немає.
