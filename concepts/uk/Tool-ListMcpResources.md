# ListMcpResources

Перелічує ресурси, які надають підключені MCP-сервери, опціонально відфільтровані до одного сервера.

## Коли використовувати

- Вам потрібно виявити, які ресурси (файли, записи, документи) пропонує MCP-сервер, перш ніж читати їх.
- Ви хочете огляд усіх ресурсів усіх підключених серверів.

## Параметри

- `server` (string, необовʼязковий): Імʼя сервера для фільтрації ресурсів. Пропустіть, щоб перелічити ресурси всіх підключених серверів.

## Приклади

### Приклад 1: Перелічити все

```
ListMcpResources()
```

### Приклад 2: Перелічити ресурси одного сервера

```
ListMcpResources(server="github")
```

## Примітки

- Це крок виявлення: передавайте цікаві URI до `ReadMcpResource` (один ресурс) або `ReadMcpResourceDir` (переліки каталогів).
- Сервери підключаються й відключаються протягом життя сесії; перелічіть знову, якщо сервер щойно додано.
