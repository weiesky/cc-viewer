# SendFile

Надсилає один або кілька файлів іншій сесії Claude Code — одноранговій сесії, переліченій через `ListAgents`, або явній адресі сесії.

## Коли використовувати

- Одноранговій сесії потрібен файл з вашого робочого каталогу (звіт, патч, фікстура), щоб продовжити власне завдання.
- Ви координуєте роботу між сесіями і хочете передати артефакти, а не лише текст (для тексту використовуйте `SendMessage`).

## Параметри

- `to` (string, обовʼязковий): Одержувач — імʼя однорангової сесії з `ListAgents` або явна адреса `uds:<socket>` / `bridge:<session id>`.
- `files` (array of strings, обовʼязковий): Шляхи файлів (абсолютні або відносні до cwd) для надсилання. Завжди передавайте масив, навіть для одного файлу. 1–16 файлів, максимум 30 МіБ кожен.
- `message` (string, необовʼязковий): Коротке повідомлення, доставлене разом із файлами.

## Приклади

### Приклад 1: Надсилання звіту одноранговій сесії

```
SendFile(
  to="teammate-a",
  files=["./dist/report.html"],
  message="The analysis you asked for"
)
```

## Примітки

- Міжсесійне передавання файлів має бути доступним у сесії; коли воно недоступне, валідація завершується помилкою «Cross-session file transfer is not available in this session.»
- Передавання на віддалені машини може вимагати додаткового затвердження.
- Читання вмісту файлу є частиною надсилання — відхиляється, якщо читання файлів вимкнено правилами дозволів.
