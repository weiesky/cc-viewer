# Projects

Керує документами проєкту в базі знань проєкту Claude користувача: читає, шукає, записує та видаляє документи або отримує інформацію про проєкт.

## Коли використовувати

- Зберегти документ (результат роботи, нотатки, довідковий матеріал) у проєкт користувача, щоб він пережив сесію.
- Прочитати чи знайти наявні документи проєкту, щоб обґрунтувати поточне завдання попереднім контекстом.
- Завантажити локальний файл у проєкт без завантаження його вмісту в контекст.
- Видалити застарілий документ проєкту.

## Параметри

- `method` (string, обовʼязковий): Одне з `project_info`, `project_read`, `project_search`, `project_write`, `project_delete`.
- `path` (string, необовʼязковий): Для `project_read`/`project_write`/`project_delete`: шлях документа. Для `project_write`: наявний шлях замінюється на місці; нове голе імʼя файлу (без "/") отримує простір імен `claude/<name>`.
- `content` (string, необовʼязковий): Для `project_write`: вбудований текст документа. Взаємовиключний із `local_path`.
- `local_path` (string, необовʼязковий): Для `project_write`: файл у робочому каталозі для завантаження — його вміст ніколи не потрапляє у ваш контекст. Взаємовиключний із `content`.
- `present_to_user` (boolean, необовʼязковий): Для `project_write`: позначити цей документ як результат, який користувач має побачити. За замовчуванням false; залиште невстановленим для рутинних збережень і масових записів.
- `query` (string, необовʼязковий): Для `project_search`: запит до бази знань.
- `n` (number, необовʼязковий): Для `project_search`: кількість збігів (за замовчуванням 5).

## Приклади

### Приклад 1: Запис результату в проєкт

```
Projects(
  method="project_write",
  path="claude/migration-plan.md",
  local_path="./migration-plan.md",
  present_to_user=true
)
```

Завантажує локальний файл, не витягуючи його вміст у контекст, і позначає його як результат для користувача.

### Приклад 2: Пошук у базі знань

```
Projects(method="project_search", query="authentication refresh tokens", n=5)
```

## Примітки

- `content` — для тексту, який ви складаєте вбудовано; `local_path` — для всього, що вже на диску — ніколи не змішуйте їх.
- Використовуйте `present_to_user=true` економно: лише для того єдиного документа, який користувач просив або з яким має діяти.
