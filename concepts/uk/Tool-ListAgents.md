# ListAgents

Перелічує агентів, яким ви можете `SendMessage`-ити: внутрішньопроцесні підагенти, яких ви породили, інші локальні сесії Claude на цій машині, ваші хмарні сесії (коли ця сесія має хмарний доступ) і — коли підключено Remote Control — інші сесії вашого облікового запису. Кожен рядок позначено за типом.

## Коли використовувати

- Вам потрібне точне імʼя сесії-піра чи підагента перед надсиланням їй повідомлення.
- Ви хочете побачити, які сесії наразі досяжні з цієї.

## Активація

- Потребує Claude Code 2.1.224+ та обміну повідомленнями між сесіями (серверний функціональний прапорець, вимкнений за замовчуванням).
- Обмін повідомленнями між сесіями недоступний на Amazon Bedrock, Claude Platform on AWS, Google Cloud Agent Platform і Microsoft Foundry.
- Вимкнено, коли встановлено `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`, `DISABLE_TELEMETRY`, `DO_NOT_TRACK` або `DISABLE_GROWTHBOOK`.
- Примусово ввімкніть через `CLAUDE_CODE_HARBOR_KITE=1`.

## Параметри

- `channel` (string, необовʼязковий): Недоступний у цій збірці; залиште невстановленим.
- `q` (string, необовʼязковий): Недоступний у цій збірці; залиште невстановленим.

## Приклади

### Приклад 1: Перелік досяжних агентів

```
ListAgents()
```

Кожен рядок друкує імʼя — це імʼя і є адресою. Надсилайте через `SendMessage({to: "<name>", message: "..."})`, копіюючи імʼя точно так, як надруковано. Додавайте ` [ref]` з рядка лише тоді, коли голе імʼя неоднозначне (два рядки мають одне імʼя, або помилка просить вас розрізнити).

## Примітки

- Лише для читання і потокобезпечний.
- Хмарна сесія отримує ваше повідомлення, але поки що не може відповісти — читайте її відповідь у власному транскрипті.
