# ReadNotifications

读取当前会话中排队等待助手处理的通知——订阅的 PR 上的 GitHub 活动（`github_webhook`）、定时触发器的触发（`trigger_fire`），以及其他 Claude 会话发来的消息（`mcp_send_message`）。

## 何时使用

- 你被告知某事发生了——订阅的 PR 有更新、定时触发器触发、另一个会话给你发了消息——并且需要实际载荷。
- 清空积压：大批通知会分批返回，因此要持续调用，直到结果报告 `remaining` 为 0。

## 参数

本工具不接受任何参数。

## 示例

### 示例 1：清空待处理通知

```
ReadNotifications()
```

按从旧到新的顺序返回排队的通知。结果中包含一个 `remaining` 计数，表示本次清空后仍排队的通知数量——再次调用本工具即可读取它们。

## 注意事项

- 每次清空有大小预算：后续调用返回的是同一队列的剩余部分（外加新到达的通知），而不只是新到达的通知。循环调用直到 `remaining` 为 0。
- 通知来源于订阅 PR 上的 GitHub webhook、定时触发器以及其他 Claude 会话的消息；当前版本没有过滤参数。
