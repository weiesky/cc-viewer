# ListPlugins

列出用户已启用的 claude.ai 插件，可选按关键词过滤。

## 何时使用

- 你需要知道已启用了哪些插件——例如，在 `SuggestPluginInstall` 卡片之后确认实际安装了什么。
- 用户询问他们有哪些插件。

## 参数

- `keywords` (array of strings, 可选)：过滤列表——最多 8 项，每项 1–64 个字符。省略则列出全部。

## 示例

### 示例 1：列出已启用的插件

```
ListPlugins()
```

### 示例 2：按关键词过滤

```
ListPlugins(keywords=["figma"])
```

## 注意事项

- 若插件目录不可达（被禁止），工具会降级为带警告的空列表，而不是失败。
- 可用性取决于会话类型和功能上线情况。
