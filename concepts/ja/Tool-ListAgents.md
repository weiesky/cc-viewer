# ListAgents

`SendMessage` を送信できる agent を一覧表示します: あなたが起動したインプロセスのサブエージェント、このマシン上の他のローカル Claude セッション、クラウドセッション (このセッションがクラウドアクセスを持つ場合)、そして — リモートコントロールが接続されている場合 — あなたのアカウントの他のセッション。各行は種類でラベル付けされます。

## 使用タイミング

- メッセージを送る前に、ピアセッションまたはサブエージェントの正確な名前が必要な場合。
- このセッションから現在到達可能なセッションを確認したい場合。

## パラメータ

- `channel` (string, optional): このビルドでは利用できません。未設定のままにしてください。
- `q` (string, optional): このビルドでは利用できません。未設定のままにしてください。

## 例

### 例 1: 到達可能な agent を一覧表示

```
ListAgents()
```

各行には名前が表示されます — その名前がアドレスです。`SendMessage({to: "<name>", message: "..."})` で、表示された名前を正確にコピーして送信してください。行の ` [ref]` は、ベア名が曖昧な場合 (2 行が同じ名前を共有する、またはエラーが曖昧性の解消を求める) にのみ付加してください。

## 注意事項

- 読み取り専用で、並行実行に対して安全です。
- クラウドセッションはメッセージを受け取りますが、まだ返信できません — その回答はそのセッション自身のトランスクリプトで読んでください。
- 可用性はセッション構成に依存します (クロスセッションメッセージングはゲート付き機能です)。
