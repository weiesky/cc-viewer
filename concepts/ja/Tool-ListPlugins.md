# ListPlugins

ユーザーの有効な claude.ai プラグインを一覧表示します。オプションでキーワードで絞り込めます。

## 使用タイミング

- どのプラグインがすでに有効かを知る必要がある場合 — 例えば、`SuggestPluginInstall` カードの後に何がインストールされたかを確認するため。
- ユーザーが自分にどのプラグインがあるかを尋ねた場合。

## パラメータ

- `keywords` (array of strings, optional): 一覧の絞り込み — 最大 8 項目、各 1〜64 文字。省略するとすべてを一覧表示します。

## 例

### 例 1: 有効なプラグインを一覧表示

```
ListPlugins()
```

### 例 2: キーワードで絞り込む

```
ListPlugins(keywords=["figma"])
```

## 注意事項

- プラグインカタログに到達できない場合 (forbidden)、ツールは失敗せずに警告付きの空リストへとデグレードします。
- 可用性はセッションタイプと機能ロールアウトに依存します。
