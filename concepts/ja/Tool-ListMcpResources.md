# ListMcpResources

接続された MCP サーバーが公開するリソースを一覧表示します。オプションで 1 つのサーバーに絞り込めます。

## 使用タイミング

- 読み取る前に、MCP サーバーが提供するリソース (ファイル、レコード、ドキュメント) を発見する必要がある場合。
- 接続されたすべてのサーバーにわたるリソースの概要が欲しい場合。

## パラメータ

- `server` (string, optional): リソースを絞り込むサーバー名。省略すると、接続されたすべてのサーバーのリソースを一覧表示します。

## 例

### 例 1: すべてを一覧表示

```
ListMcpResources()
```

### 例 2: 1 つのサーバーのリソースを一覧表示

```
ListMcpResources(server="github")
```

## 注意事項

- これは発見のステップです: 興味深い URI を `ReadMcpResource` (単一リソース) または `ReadMcpResourceDir` (ディレクトリ一覧) に渡してください。
- サーバーはセッションの寿命の間に接続と切断を繰り返します。サーバーが追加されたばかりの場合は再一覧表示してください。
