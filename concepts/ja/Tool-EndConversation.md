# EndConversation

現在の会話を終了し、それ以上のメッセージの送信を防ぎます。

## 使用タイミング

- 持続的なユーザーによる悪用の場合、またはユーザーがこのツールのデモンストレーションを明示的に要求した場合のみ。

これは最後の手段のアクションです: ツール自身のルールは、使用前にユーザーへの警告と確認を要求し、自傷や危害に関連する状況では決して使用してはなりません。

## 有効化

- Claude Code 2.1.213+ と Opus 4.8 / Sonnet 5 / Fable 5 以降のファミリーのモデルが必要です。
- 対話型ターミナルセッションのみ — `--bare` モードでは使用できず、サブエージェントにも提供されません。
- Amazon Bedrock、Claude Platform on AWS、Vertex AI、Microsoft Foundry、クラウドゲートウェイでは利用できません。
- サーバーサイドの機能フラグが必要です — ほとんどのセッションではこのツールは提供されません。

## パラメータ

このツールはパラメータを取りません。

## 例

### 例 1: 会話を終了

```
EndConversation()
```

フローは 2 ステップです: 最初の呼び出しはリフレクションメッセージを返します。直後の 2 回目の呼び出しが実際に会話を終了します (`ended: true`)。

## 注意事項

- 強くゲートされています: サポート対象モデル、CLI エントリポイント、サーバーサイドの機能フラグが必要です — ほとんどのセッションではこのツールは提供されません。
- 一度終了すると、会話内でそれ以上のメッセージを送信できません。
