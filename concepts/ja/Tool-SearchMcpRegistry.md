# SearchMcpRegistry

MCP コネクタレジストリをキーワードで検索し、タスクの完了に役立つ可能性のあるコネクタを発見します。

## 使用タイミング

- タスクが外部サービス (データベース、イシュートラッカー、SaaS API) の恩恵を受ける場合に、それに対応する MCP コネクタが存在するか確認したいとき。
- ユーザーが製品名を挙げて接続を求めた場合 — レジストリを検索して一致するコネクタを探してください。

## パラメータ

- `keywords` (array of strings, required): ユーザーの意図または名前付き製品を説明するキーワードフレーズ。1〜8 項目、各 1〜64 文字。

## 例

### 例 1: 名前付き製品のコネクタを探す

```
SearchMcpRegistry(keywords=["linear", "issue tracker"])
```

キーワードに一致するコネクタを持つレジストリエントリを返します。コネクタの完全な詳細は `SuggestConnectors` で解決してください。

## 注意事項

- 読み取り専用で、並行実行に対して安全です。結果のサイズには上限があります。
- ファーストパーティ API 上のリモート (claude.ai) セッションでのみ利用可能です。
- 検索は何もインストールしません — 純粋に発見のためのものです。
