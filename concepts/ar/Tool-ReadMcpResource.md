# ReadMcpResource

يقرأ مورداً واحداً يعرضه خادم MCP (Model Context Protocol) متصل، مُعنوناً عبر URI الخاص به.

## متى يُستخدم

- يعلن خادم MCP عن مورد (ملف أو سجل أو مستند) تحتاج محتواه في السياق.
- لديك URI مورد محدد — من `ListMcpResources` أو من توثيق الخادم أو من نتيجة أداة سابقة.

## المعاملات

- `server` (سلسلة، مطلوب): اسم خادم MCP.
- `uri` (سلسلة، مطلوب): URI المورد المطلوب قراءته.

## أمثلة

### مثال 1: قراءة مورد خادم عبر URI

```
ReadMcpResource(server="github", uri="file:///repo/docs/architecture.md")
```

يُعيد محتوى المورد كما يوفره خادم MCP `github`.

## ملاحظات

- استخدم `ListMcpResources` أولاً إذا كنت لا تعرف الموارد التي يعرضها الخادم؛ واستخدم `ReadMcpResourceDir` لقوائم ذات أسلوب الدليل.
- مخطط URI خاص بكل خادم (`file://` أو `https://` أو مخططات مخصصة) — تحقق مما يعلنه الخادم المستهدف.
