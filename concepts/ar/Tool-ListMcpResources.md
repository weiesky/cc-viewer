# ListMcpResources

يسرد الموارد التي تعرضها خوادم MCP المتصلة، مع إمكانية التصفية الاختيارية إلى خادم واحد.

## متى يُستخدم

- تحتاج اكتشاف الموارد (ملفات أو سجلات أو مستندات) التي يقدمها خادم MCP قبل قراءتها.
- تريد نظرة عامة على كل الموارد عبر كل خادم متصل.

## المعاملات

- `server` (سلسلة، اختياري): اسم الخادم لتصفية الموارد به. احذفه لسرد الموارد من جميع الخوادم المتصلة.

## أمثلة

### مثال 1: سرد كل شيء

```
ListMcpResources()
```

### مثال 2: سرد موارد خادم واحد

```
ListMcpResources(server="github")
```

## ملاحظات

- هذه خطوة الاكتشاف: مرر URIs المثيرة للاهتمام إلى `ReadMcpResource` (مورد واحد) أو `ReadMcpResourceDir` (قوائم أدلة).
- تتصل الخوادم وتنفصل على مدى عمر الجلسة؛ أعد السرد إذا أُضيف خادم للتو.
