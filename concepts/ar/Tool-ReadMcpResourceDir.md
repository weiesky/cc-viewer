# ReadMcpResourceDir

يسرد مدخلات مورد بأسلوب دليل يعرضه خادم MCP متصل، مُعنوناً عبر URI الخاص به.

## متى يُستخدم

- ينظم خادم MCP موارده هرمياً وتحتاج تعداد مستوى واحد من ذلك التسلسل الهرمي.
- تريد التصفح قبل قراءة الموارد الفردية بـ `ReadMcpResource`.

## التفعيل

- مفعَّل دائماً، لكنه غير معروض في قائمة أدوات النموذج — مُخصَّص لاستخدام thin-client / sidecar.

## المعاملات

- `server` (سلسلة، مطلوب): اسم خادم MCP.
- `uri` (سلسلة، مطلوب): URI مورد الدليل المطلوب سرده.

## أمثلة

### مثال 1: سرد دليل موارد

```
ReadMcpResourceDir(server="filesystem", uri="file:///project/src/")
```

يُعيد المدخلات الفرعية التي يعرضها الخادم تحت URI ذلك الدليل.

## ملاحظات

- فقط الخوادم التي تصمم مواردها كأدلة تدعم هذا؛ الخوادم المسطحة ستعيد خطأً أو قائمة فارغة — ارجع إلى `ListMcpResources`.
- ادمجها مع `ReadMcpResource` للتعمق في المدخلات التي تبدو ذات صلة.
