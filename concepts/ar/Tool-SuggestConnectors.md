# SuggestConnectors

يستخرج حمولات الموصلات الكاملة لقيم `directoryUuid` التي أعادها `SearchMcpRegistry`، حتى يُعرض على المستخدم موصلات ملموسة لتفعيلها.

## متى يُستخدم

- بعد أن يُعيد `SearchMcpRegistry` موصلات مرشحة، لجلب تفاصيلها الكاملة للعرض.

## التفعيل

- متاح فقط في الجلسات البعيدة (claude.ai) عبر واجهة API الرسمية.

## المعاملات

- `uuids` (مصفوفة سلاسل، مطلوب): قيم `directoryUuid` أو `server_id` المطلوب استخراجها. من 1 إلى 32 عنصراً، كل عنصر من 1 إلى 64 حرفاً.

## أمثلة

### مثال 1: استخراج نتيجتي سجل

```
SuggestConnectors(uuids=["d290f1ee-6c54-4b01-90e6-d701748f0851", "a1b2c3d4-0000-4000-8000-abcdefabcdef"])
```

## ملاحظات

- لا تخمِّن UUIDs أبداً — استخرج فقط المعرفات التي جاءت من `SearchMcpRegistry`.
- الأداة لا توصِّل شيئاً بنفسها؛ تفعيل الموصل يتم خارج نطاقها.
