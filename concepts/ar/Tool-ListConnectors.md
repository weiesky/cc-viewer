# ListConnectors

يسرد موصلات MCP المثبتة لمؤسسة المستخدم على claude.ai، مع تصفية اختيارية بالكلمات المفتاحية.

## متى يُستخدم

- تحتاج معرفة الموصلات المثبتة بالفعل قبل اقتراح موصلات جديدة.
- يسأل المستخدم عن عمليات التكامل التي تمتلكها مؤسسته.

## المعاملات

- `keywords` (مصفوفة سلاسل، اختياري): تصفية القائمة — حتى 8 عناصر، كل عنصر من 1 إلى 64 حرفاً. احذفه لسرد كل شيء.

## أمثلة

### مثال 1: سرد كل الموصلات المثبتة

```
ListConnectors()
```

### مثال 2: التصفية بالكلمة المفتاحية

```
ListConnectors(keywords=["github"])
```

## ملاحظات

- متاحة فقط في جلسات claude.ai البعيدة عبر واجهة API الرسمية.
- اقرنها بـ `SearchMcpRegistry` (الاكتشاف) و`SuggestConnectors` (التفاصيل) لتدفق البحث والتفعيل الكامل.
