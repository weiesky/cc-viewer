# ListAgents

يسرد الوكلاء الذين يمكنك إرسال رسالة إليهم عبر `SendMessage`: الوكلاء الفرعيون داخل العملية الذين أنشأتهم، وجلسات Claude المحلية الأخرى على هذا الجهاز، وجلساتك السحابية (عند توفر وصول سحابي لهذه الجلسة)، و— عند اتصال Remote Control — جلسات حسابك الأخرى. كل صف مُوسوم بنوعه.

## متى يُستخدم

- تحتاج الاسم الدقيق لجلسة نظيرة أو وكيل فرعي قبل إرسال رسالة إليه.
- تريد رؤية الجلسات القابلة للوصول حالياً من هذه الجلسة.

## التفعيل

- يتطلب Claude Code 2.1.224+ والمراسلة عبر الجلسات (علَم ميزة من جهة الخادم، معطَّل افتراضياً).
- المراسلة عبر الجلسات غير متاحة على Amazon Bedrock وClaude Platform on AWS وGoogle Cloud Agent Platform وMicrosoft Foundry.
- معطَّل عند ضبط `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` أو `DISABLE_TELEMETRY` أو `DO_NOT_TRACK` أو `DISABLE_GROWTHBOOK`.
- يمكن فرض تفعيله بـ `CLAUDE_CODE_HARBOR_KITE=1`.

## المعاملات

- `channel` (سلسلة، اختياري): غير متاح في هذا البناء؛ اتركه غير مضبوط.
- `q` (سلسلة، اختياري): غير متاح في هذا البناء؛ اتركه غير مضبوط.

## أمثلة

### مثال 1: سرد الوكلاء القابلين للوصول

```
ListAgents()
```

يطبع كل صف اسماً — ذلك الاسم هو العنوان. أرسل بـ `SendMessage({to: "<name>", message: "..."})` ناسخاً الاسم تماماً كما طُبع. ألحق ` [ref]` الخاص بصف فقط عندما يكون الاسم المجرد ملتبساً (يتشاركه صفان، أو يطلب خطأ التوضيح).

## ملاحظات

- للقراءة فقط وآمن مع التزامن.
- تستقبل الجلسة السحابية رسالتك لكنها لا تستطيع الرد بعد — اقرأ إجابتها في نصها (transcript) الخاص.
