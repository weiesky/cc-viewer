# SendUserFile

يرسل ملفاً واحداً أو أكثر إلى المستخدم — نواتج مولدة أو لقطات شاشة أو تقارير — مع تحكم في طريقة عرض العميل لها.

## متى يُستخدم

- أنتجت ملفاً يحتاجه المستخدم (تقرير، صورة، صفحة HTML) وتريد إظهاره لا مجرد ذكر مساره.
- الرد بمرفق (`status="normal"`)، أو إظهار شيء لم يطلبه المستخدم لكنه يحتاج رؤيته الآن استباقياً (`status="proactive"`).

## المعاملات

- `files` (مصفوفة سلاسل، مطلوب): مسارات الملفات (مطلقة أو نسبة إلى cwd) للإرسال إلى المستخدم. مرر دائماً مصفوفة حتى لملف واحد.
- `caption` (سلسلة، اختياري): تعليق قصير للملف (أو الملفات).
- `status` (سلسلة، مطلوب): `proactive` عند إظهار ملف لم يطلبه المستخدم ويحتاج رؤيته الآن — ناتج مولّد أو تقرير مكتمل؛ و`normal` عند الرد على شيء قاله المستخدم للتو.
- `display` (سلسلة، اختياري): `render` يفتح الملف مضمناً في اللوحة الجانبية (HTML وSVG وMermaid وصور وPDF)؛ و`attach` يعرض بطاقة تنزيل فقط (مخرجات سيحفظها المستخدم ويفتحها في مكان آخر). احذفه ليقرر العميل حسب نوع الملف.

## أمثلة

### مثال 1: تسليم تقرير مولّد

```
SendUserFile(
  files=["./out/weekly-report.html"],
  caption="Weekly usage report",
  status="proactive",
  display="render"
)
```

## ملاحظات

- يتطلب أن تسمح الجلسة بإرسال الملفات (قدرة خاضعة للإعدادات/بوابات الميزات)؛ لا يُعرض في وضع brief.
- اختر `display="attach"` للملفات التي يحفظها المستخدم ويفتحها في تطبيق آخر؛ و`render` لأي شيء يجب أن يطالعه فوراً.
