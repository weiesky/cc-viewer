# SendFile

يرسل ملفاً واحداً أو أكثر إلى جلسة Claude Code أخرى — نظير مُدرج بواسطة `ListAgents`، أو عنوان جلسة صريح.

## متى يُستخدم

- تحتاج جلسة نظيرة ملفاً من دليل عملك (تقرير، تصحيح، عيّنة اختبار) لمتابعة مهمتها.
- تنسق العمل عبر الجلسات وتريد تسليم نواتج لا مجرد نص (استخدم `SendMessage` للنص).

## المعاملات

- `to` (سلسلة، مطلوب): المستلم — اسم جلسة نظيرة من `ListAgents`، أو عنوان صريح `uds:<socket>` / `bridge:<session id>`.
- `files` (مصفوفة سلاسل، مطلوب): مسارات الملفات (مطلقة أو نسبة إلى cwd) للإرسال. مرر دائماً مصفوفة حتى لملف واحد. من 1 إلى 16 ملفاً، بحد أقصى 30 MiB لكل ملف.
- `message` (سلسلة، اختياري): رسالة قصيرة تُسلم مع الملفات.

## أمثلة

### مثال 1: إرسال تقرير إلى جلسة نظيرة

```
SendFile(
  to="teammate-a",
  files=["./dist/report.html"],
  message="The analysis you asked for"
)
```

## ملاحظات

- يجب أن يكون نقل الملفات عبر الجلسات متاحاً في الجلسة؛ وإلا يفشل التحقق برسالة "Cross-session file transfer is not available in this session."
- قد تتطلب عمليات النقل إلى أجهزة بعيدة موافقة إضافية.
- قراءة محتويات الملف جزء من الإرسال — يُرفض إذا عطَّلت قواعد الأذونات قراءة الملفات.
