# REPL

ينفذ JavaScript في سياق vm خاص بـ Node.js دائم داخل الجلسة. يُدعَم `await` على المستوى الأعلى، وتبقى المتغيرات/الدوال المعرَّفة في استدعاء واحد متاحة في الاستدعاءات اللاحقة.

## متى يُستخدم

- حسابات سريعة أو تحويل بيانات أو معالجة JSON أسهل في الكود منها في أسطر shell المنفردة.
- برمجة متعددة الخطوات يجب أن تستمر فيها الحالة الوسيطة بين الاستدعاءات (عدادات، نتائج متراكمة).
- استكشاف سلوك واجهة API أو مكتبة تفاعلياً قبل كتابته في ملف.

## التفعيل

- معطَّل افتراضياً — اضبط `CLAUDE_CODE_REPL=true` لتفعيله.
- في جلسات الطرفية (`cli`) و claude.ai (`remote`)، قد يفعِّله أيضاً علَم ميزة من جهة الخادم.
- عند إيقافه، يُخفى REPL من قائمة أدوات النموذج. وعند تشغيله، تحل اختصارات REPL محل `Read` و`Glob` و`Grep` و`Bash` و`PowerShell` و`NotebookEdit`.

## المعاملات

- `code` (سلسلة، مطلوب): كود JavaScript المطلوب تنفيذه. يدعم await على المستوى الأعلى. تستمر الحالة عبر الاستدعاءات.
- `description` (سلسلة، اختياري): وصف واضح وموجز لما يفعله هذا السكريبت بصيغة المبني للمعلوم (5–10 كلمات)، مثل "Trace upgrade message to its GrowthBook flag".
- `timeout` (عدد، اختياري): المهلة بالمللي ثانية. القيمة الافتراضية 30000؛ والحد الأقصى 600000.

## أمثلة

### مثال 1: حساب حالة وإعادة استخدامها

```
REPL(code="const counts = new Map(); ['a','b','a'].forEach(k => counts.set(k, (counts.get(k)||0)+1)); counts.get('a')")
```

يُعيد `2`؛ ويبقى `counts` معرَّفاً لاستدعاءات REPL اللاحقة في الجلسة نفسها.

### مثال 2: await على المستوى الأعلى مع مهلة أطول

```
REPL(
  code="const res = await fetch('https://example.com/api'); await res.json()",
  description="Fetch example API and parse JSON",
  timeout=60000
)
```

## ملاحظات

- الحالة لكل جلسة: إعادة تشغيل الجلسة تمسح كل التعريفات.
- هذه بيئة JavaScript (Node) — استخدم Bash لأوامر shell أو الأعمال كثيفة الملفات أو بيئات التشغيل غير JS.
- يجب أن يحدد الكود طويل الأمد `timeout` صراحةً؛ فالافتراضي 30 ثانية يقتل أي شيء أبطأ.
