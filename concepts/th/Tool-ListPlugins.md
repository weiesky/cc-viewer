# ListPlugins

แสดงรายการ plugin ของ claude.ai ที่ผู้ใช้เปิดใช้งานอยู่ กรองด้วย keyword ได้ (ไม่บังคับ)

## เมื่อใดควรใช้

- คุณต้องรู้ว่า plugin ใดเปิดใช้งานอยู่แล้ว — เช่น เพื่อยืนยันสิ่งที่ติดตั้งหลังการ์ด `SuggestPluginInstall`
- ผู้ใช้ถามว่าพวกเขามี plugin อะไรบ้าง

## พารามิเตอร์

- `keywords` (array of strings, optional): กรองรายการ — ไม่เกิน 8 รายการ แต่ละรายการ 1–64 ตัวอักษร ละเว้นเพื่อแสดงทั้งหมด

## ตัวอย่าง

### ตัวอย่างที่ 1: แสดงรายการ plugin ที่เปิดใช้งาน

```
ListPlugins()
```

### ตัวอย่างที่ 2: กรองด้วย keyword

```
ListPlugins(keywords=["figma"])
```

## หมายเหตุ

- หาก plugin catalog เข้าถึงไม่ได้ (forbidden) เครื่องมือจะลดระดับเป็นรายการว่างพร้อมคำเตือนแทนที่จะล้มเหลว
- ความพร้อมใช้งานขึ้นอยู่กับประเภทเซสชันและ feature rollout
