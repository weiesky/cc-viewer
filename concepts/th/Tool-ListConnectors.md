# ListConnectors

แสดงรายการ MCP connector ที่ติดตั้งไว้สำหรับองค์กร claude.ai ของผู้ใช้ กรองด้วย keyword ได้ (ไม่บังคับ)

## เมื่อใดควรใช้

- คุณต้องรู้ว่า connector ใดติดตั้งอยู่แล้วก่อนเสนออันใหม่
- ผู้ใช้ถามว่าองค์กรของพวกเขามี integration อะไรบ้าง

## การเปิดใช้งาน

- พร้อมใช้งานในเซสชันระยะไกล (claude.ai) บน first-party API เท่านั้น

## พารามิเตอร์

- `keywords` (array of strings, optional): กรองรายการ — ไม่เกิน 8 รายการ แต่ละรายการ 1–64 ตัวอักษร ละเว้นเพื่อแสดงทั้งหมด

## ตัวอย่าง

### ตัวอย่างที่ 1: แสดงรายการ connector ที่ติดตั้งทั้งหมด

```
ListConnectors()
```

### ตัวอย่างที่ 2: กรองด้วย keyword

```
ListConnectors(keywords=["github"])
```

## หมายเหตุ

- ใช้คู่กับ `SearchMcpRegistry` (ค้นพบ) และ `SuggestConnectors` (รายละเอียด) สำหรับ flow ค้นหา-และ-เปิดใช้งานแบบเต็ม
