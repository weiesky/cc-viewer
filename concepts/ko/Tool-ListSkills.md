# ListSkills

사용자의 활성화된 claude.ai 스킬을 나열하며, 선택적으로 키워드로 필터링합니다.

## 사용 시점

- 현재 활성화된 스킬의 권위 있는 목록이 필요합니다 — 스킬을 호출하기 전에, 또는 `SuggestSkills` 카드가 추가한 것을 확인하기 위해.
- 사용자가 어떤 스킬을 갖고 있는지 묻습니다.

## 활성화

- 플러그인 레지스트리 접근 권한이 필요합니다.
- HIPAA 환경에서는 비활성화됩니다.
- 원격 세션에서는 항상 사용할 수 있습니다.

## 매개변수

- `keywords` (array of strings, 선택): 목록 필터 — 최대 8개 항목, 각각 1-64자. 생략하면 전체를 나열합니다.

## 예시

### 예시 1: 활성화된 스킬 나열

```
ListSkills()
```

### 예시 2: 키워드로 필터링

```
ListSkills(keywords=["review"])
```

## 참고사항

- 카탈로그에 도달할 수 없는 경우(forbidden), 도구는 실패하는 대신 경고와 함께 빈 목록으로 저하됩니다.
- 이것은 *활성화된* 스킬을 나열합니다. 사용자가 추가할 수 있는 스킬을 표시하려면 `SuggestSkills`를 사용하십시오.
