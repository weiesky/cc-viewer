# ListPlugins

사용자의 활성화된 claude.ai 플러그인을 나열하며, 선택적으로 키워드로 필터링합니다.

## 사용 시점

- 이미 활성화된 플러그인을 알아야 합니다 — 예를 들어 `SuggestPluginInstall` 카드 후에 설치된 것을 확인하기 위해.
- 사용자가 어떤 플러그인을 갖고 있는지 묻습니다.

## 활성화

- 플러그인 레지스트리 접근 권한이 필요합니다.
- 사용 가능 여부는 세션 유형과 기능 롤아웃에 따라 다릅니다 — HIPAA 환경에서는 비활성화되고, 원격 세션에서는 항상 사용할 수 있습니다.

## 매개변수

- `keywords` (array of strings, 선택): 목록 필터 — 최대 8개 항목, 각각 1-64자. 생략하면 전체를 나열합니다.

## 예시

### 예시 1: 활성화된 플러그인 나열

```
ListPlugins()
```

### 예시 2: 키워드로 필터링

```
ListPlugins(keywords=["figma"])
```

## 참고사항

- 플러그인 카탈로그에 도달할 수 없는 경우(forbidden), 도구는 실패하는 대신 경고와 함께 빈 목록으로 저하됩니다.
