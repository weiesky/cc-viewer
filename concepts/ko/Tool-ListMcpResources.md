# ListMcpResources

연결된 MCP 서버가 노출하는 리소스를 나열하며, 선택적으로 한 서버로 필터링합니다.

## 사용 시점

- 읽기 전에 MCP 서버가 제공하는 리소스(파일, 레코드, 문서)를 발견해야 합니다.
- 연결된 모든 서버의 전체 리소스 개요를 원합니다.

## 매개변수

- `server` (string, 선택): 리소스를 필터링할 서버 이름. 생략하면 연결된 모든 서버의 리소스를 나열합니다.

## 예시

### 예시 1: 전체 나열

```
ListMcpResources()
```

### 예시 2: 한 서버의 리소스 나열

```
ListMcpResources(server="github")
```

## 참고사항

- 이것은 발견 단계입니다: 흥미로운 URI를 `ReadMcpResource`(단일 리소스) 또는 `ReadMcpResourceDir`(디렉터리 목록)로 넣으십시오.
- 서버는 세션 수명 동안 연결되고 해제됩니다. 서버가 방금 추가되었다면 다시 나열하십시오.
