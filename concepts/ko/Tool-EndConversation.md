# EndConversation

현재 대화를 종료하고 이후 어떤 메시지도 전송되지 않도록 합니다.

## 사용 시점

- 지속적인 사용자 학대, 또는 사용자가 이 도구의 시연을 명시적으로 요청하는 경우에만.

이것은 최후의 수단입니다: 도구 자체의 규칙이 사용 전에 먼저 경고하고 확인할 것을 요구하며, 자해 또는 위해 관련 상황에서는 절대 사용해서는 안 됩니다.

## 활성화

- Claude Code 2.1.213+ 및 Opus 4.8 / Sonnet 5 / Fable 5 이상 제품군의 모델이 필요합니다.
- 대화형 터미널 세션 전용입니다 — `--bare` 모드에서는 절대 제공되지 않으며, 서브에이전트에게는 제공되지 않습니다.
- Amazon Bedrock, AWS의 Claude Platform, Vertex AI, Microsoft Foundry, 또는 클라우드 게이트웨이에서는 사용할 수 없습니다.
- 서버 측 기능 플래그가 필요합니다 — 대부분의 세션은 이 도구를 제공하지 않습니다.

## 매개변수

이 도구는 매개변수를 받지 않습니다.

## 예시

### 예시 1: 대화 종료

```
EndConversation()
```

흐름은 2단계입니다: 첫 호출은 반영 메시지를 반환하고, 곧바로 이어지는 두 번째 호출이 실제로 대화를 종료합니다(`ended: true`).

## 참고사항

- 강하게 게이트되어 있습니다: 지원되는 모델, CLI 진입점, 서버 측 기능 플래그가 필요합니다 — 대부분의 세션은 이 도구를 제공하지 않습니다.
- 일단 종료되면 대화에서 더 이상 메시지를 보낼 수 없습니다.
